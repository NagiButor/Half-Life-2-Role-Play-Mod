# HL2RPM — вход для AI-агента

Это настоящий git-корень HL2RPM. Общие правила не зависят от модели или AI-клиента.

Перед работой **прочитать полностью**:
1. [AI_instructions/PROJECT.md](AI_instructions/PROJECT.md).
2. [AI_instructions/CURRENT_STATUS.md](AI_instructions/CURRENT_STATUS.md).
3. Нужную тему `AI_instructions/topics/*.md` и процедуру `AI_instructions/skills/<имя>/SKILL.md` из оглавления.

Отвечать по-русски. **Не менять `.vpc`, не запускать VPC / `create*projects.bat`**. Сборка — Win32/episodic/Release; шейдеры — только ShaderCompile235 и только нужные. Коммит/пуш — по просьбе пользователя. В рабочем дереве есть существенные незакоммиченные изменения: сначала изучить их. После работы обновить общие файлы статуса/тем.
