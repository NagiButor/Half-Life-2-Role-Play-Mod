# Звук: музыка, фразы NPC, субтитры, локации, звуковые сцены (озвучка - voice.md)

> Общая техническая справка для любой AI-модели. Правила — `../PROJECT.md`, статус — `../CURRENT_STATUS.md`. Новые знания по теме добавлять сюда; датированные результаты сверять с текущим кодом.

## Паузы и защита от повторов, 2026-11-04

В `game/server/hl2rpm_audio.cpp` после старого описания M4 добавлены общая память произнесённых текстов (`s_SaidTexts`), речевой семафор для очередности NPC и общая пауза idle улицы. `rpm_bark_gap` = 2 с после реплики, `rpm_bark_repeat` = 150 с до повтора того же текста другим NPC (срочные — 20 с), `rpm_bark_idle_gap_min/max` = 18/45 с. Приветствия также имеют общую отсечку. Правка предназначена для жалобы на одновременные одинаковые фразы рабочих/гражданских; есть старый игровой прогон с разнесёнными репликами, но полного пользовательского подтверждения нет. При продолжении смотреть текущий код и `CURRENT_STATUS.md`.

## Устройство систем M4 и исторические решения

- **Звук CK** (2026-10-31, M4; сервер `hl2rpm_audio.cpp/.h`, клиент `hl2rpm_music.cpp`, `hl2rpm_subtitles.cpp`; CK `dlgedit/sounddata.py`, `ui/sound_pages.py`, вкладка «Звук» и вкладка NPC «Фразы»). **Музыка** `scripts/rpg/music.txt` (`"Music" { "tracks" { "<id>" { file volume kind explore|combat|location|stinger time any|day|night maps event } } }`): сервер раз в 0.5 с выбирает настроение — действие `music` (переопределение, `RPMState` "music") > бой (враг в `NPC_STATE_COMBAT` с врагом-игроком в 2500 ед., ещё 8 с) > музыка зоны-локации > исследование (день 6–21 ч) — и шлёт `rpm_music_set "<mood>~file:vol;…"`; клиент играет `#<файл>` (громкость `snd_musicvolume` × `snd_rpm_music`), перекрёстное затухание, пауза 12–40 с между треками исследования, стингеры (`rpm_music_stinger`, события location / quest_start / quest_complete / quest_fail или действие `stinger`) приглушают музыку до 0.35. **Ловушка**: движок различает фоновые звуки по имени — повторный старт трека, который ещё затухает, подхватывает его (`resume`), а не запускает копию (`SND_STOP` по имени глушил обе). **Фразы NPC** («барки»): `barks` в `scripts/npcs/<npc>.txt` и наборы `scripts/rpg/barks.txt` (`classes`); у NPC из CK `bark_sets` — пусто = наборы своего класса (как у NPC из Hammer), `-` = без общих; события greet, idle, farewell, hurt, combat, weapon, ally_death, kill (value), package (value), custom (только действием `bark`); у строки `text(_язык)`, `choreo(_язык)` (сцена CK с липсинком — файлы `bark_<id>` в `sound/dialogs/` и `scenes/dialogs/<npc или barks_<набор>>/<язык>/`), `sound`, weight, cooldown, once (`RPMState` "barks"), chance, conditions. Субтитры — `rpm_subtitle` → `HudRPMSubtitles` (не меньше времени чтения: символы UTF-8 / 16 в с). **Без Фримена**: `scripts/hl2rpm_speech_block.txt` (`hl2rpm_extras/tools/make_speech_block.py`), `RPMSpeech::Allow` в `SpeakDispatchResponse`; `stock_speech` all|combat|none (по умолчанию у NPC из CK — combat), для остальных `rpm_stock_speech`. **Локация** — зона с `display_name(_язык)` (уведомление «Новая локация», `discover_xp`, стингер location; `RPMState` "locations"), `music` (id треков), `soundscape` (сервер ставит `env_soundscape_triggerable` + коробочный `trigger_soundscape`); звуковые сцены — `scripts/soundscapes_hl2rpm.txt` (грузят `soundscape_system.cpp` и клиентский `c_soundscape.cpp`). Ref `sound` — `ambient_generic` (sound, volume, radius, everywhere; время/задания — присутствием). Консоль: `rpm_audio_debug 1`, `rpm_music_dump`, `rpm_music_status` (клиент), `snd_rpm_music_debug 1`, `rpm_bark <npc> <событие>`, `rpm_speech_check`, `rpm_speech_block_reload`. Уведомления (`ui_toast`) держатся по длине текста (2.5–6 с). CK: импорт музыки (MP3 — как есть, прочее — ffmpeg в MP3) в `sound/music/hl2rpm/`, выбор звуков игры из VPK с прослушиванием (`SoundPicker`), F7 проверяет треки, сцены, наборы.
