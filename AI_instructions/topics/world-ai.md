# Мир в игре: слой карты, распорядок NPC, навигация открытых карт

> Общая техническая справка для любой AI-модели. Правила — `../PROJECT.md`, статус — `../CURRENT_STATUS.md`. Новые знания по теме добавлять сюда.

### Мир в игре: слой карты и распорядок NPC (`game/server/hl2rpm_world.cpp`, `hl2/ai_behavior_rpmroutine.cpp`)

- **Слой карты** создаётся один раз — на новой карте (`LevelInitPostEntity`, не при загрузке сохранения и не при возврате на посещённую карту: эти сущности приходят из сохранения). Описания (NPC, пути, маркеры, фракции) перечитываются при каждой загрузке уровня. Сущности слоя помечены контекстом `rpmref:<id>`. Типы: `npc` (по описанию из `scripts/npcs`), `marker` (= `ai_hint` HINT_WORLD_WORK_POSITION, группа `rpm_marker`, анимация — имя из `actbusy.txt`), `item`, `container` (`prop_loot_container` — проп с лутом, USE открывает окно лута; `ILootContainer` в `loot_container.h`), `prop` (`prop_dynamic_override` / `prop_physics_override`), `path` (только данные), `entity`. Консоль: `rpm_world_reload [1]` (перечитать; с 1 — пересоздать сущности слоя; F8 программы шлёт его через `-hijack`), `rpm_world_dump`, `rpm_ai_debug 1/2` (над NPC — пакет и состояние).
- **Распорядок** — поведение `CAI_RPMRoutineBehavior`, добавлено последним у `CNPC_PlayerCompanion` (горожане, Аликс, Барни, вортигонты), `CNPC_MetroPolice`, `CNPC_Combine`, `CNPC_BaseZombie`; у остальных классов распорядка нет. Работает первый пакет списка, у которого подходит время (`WorldClock_GetHours`) и условия квеста; пакеты: sleep, eat, sandbox, patrol, wander, travel, guard, use_marker, wait, follow, talk. Анимации у маркеров играет **actbusy** этого же NPC (`ForceActBusy(NULL, hint, 0)` — 0 = до конца пакета; после — `Disable()`, чтобы actbusy не искал хинты карты сам); `CAI_ActBusyBehavior::CanPlayActBusy` проверяет, есть ли анимация у модели. Бой, скрипты, отряд игрока и диалог с игроком прерывают распорядок (`BlockedReason`); диалог — по `RPMWorld::NoteDialogActivity` из `dialogsystem_server.cpp`.
- **Ловушки**: (1) HL2 сам набирает дружелюбных горожан в отряд игрока (`npc_citizen_auto_player_squad`) — у NPC с описанием ставится `SF_CITIZEN_NOT_COMMANDABLE`, если не задано `commandable`. (2) Метрокопы/солдаты по классу враждебны горожанам — без фракций с нейтральными отношениями на тестовой карте полиция убивает горожан в первые секунды. Отношения фракций применяются сразу после создания слоя и при изменении набора NPC; отношение к игроку — один раз на NPC (`m_bRPMPlayerRelation`, сохраняется: иначе «прощался» бы гнев после урона). (3) `essential` — `CAI_BaseNPC::OnTakeDamage_Alive` не опускает здоровье ниже 1.
- **Навигация открытых карт**: на большинстве карт мода нет `info_node` (у `rpm_trainstation` — 0). `rpm_nav_generate [шаг 128] [макс] [файл]` раскладывает узлы обходом сетки трассами хулла NPC (шаги ≤ 18, спуски ≤ 40, без воды) от игрока, NPC и маркеров; узлы из `scripts/world/<карта>_nav.txt` добавляются в граф (`AddNode` в `LevelInitPostEntity`, если граф строится заново); изменение файла (CRC в `maps/graphs/<карта>.rpmnav`) удаляет `.ain` → граф перестраивается при загрузке. `MAX_NODES` поднят 1500 → 8192 (`ai_network.h`). Программа вызывает генерацию через запуск игры (Навигация → Сгенерировать в игре).
