## Слитые исходники движка (только справочник)

`E:\SourceModding\UsefulStuff\source-engine-master (for learning)` — слив TF2 2018 г. (форк nillerusr). Наш рантайм — закрытые DLL из `Source SDK Base 2013 Singleplayer\bin` (ветка 2013–2015 гг.), и большая часть их кода в сливе та же. Прежде чем часами выяснять поведение закрытой DLL опытом, посмотреть её код здесь.

- **Только читать.** Код в репозиторий не копировать даже кусками; исправления писать своими словами по пониманию поведения, как всё в этом файле. Иначе — риск DMCA для GitHub-репозитория, проблемы с релизом в Steam и конфликт с политикой Mapbase no-leak. Слив держать вне репозитория, движок из него не собирать (такой билд нельзя распространять).
- **Подсказка, а не истина**: ветка новее нашей (TF2 2018 против SP 2013/2015). Гипотезу проверять на настоящем бинарнике — cdb (смещения, дизассемблер), A/B в игре; смещения и раскладка структур могут отличаться (поэтому `hl2rpm_psconstants.cpp` ищет массивы по маркеру, а не по адресу). Для x64-движка 2025 г. слив почти бесполезен (см. «x64 / MP-база 2025»).
- **Где что**: `engine.dll` → `engine\` (мир `gl_rsurf.cpp`, тени `shadowmgr.cpp`, сохранения и переходы `host_saverestore.cpp`, `cl_localnetworkbackdoor.cpp`); `shaderapidx9.dll` → `materialsystem\shaderapidx9\` (`shaderapidx8.cpp` — константы, состояния, RT; `hardwareconfig.cpp`); `MaterialSystem.dll` → `materialsystem\` (очередь `cmatqueuedrendercontext.cpp`, материалы, текстуры); `StudioRender.dll` → `studiorender\`; `vphysics.dll` → `vphysics\` (сохранение и перепривязка указателей — `vphysics_saverestore.cpp`); `FileSystem_Stdio.dll` → `filesystem\`; `datacache.dll` → `datacache\`; `GameUI.dll` → `gameui\` (`OptionsDialog.cpp` — наши страницы «Настроек» держатся на его внутренностях); `vgui2.dll` / `vguimatsurface.dll` → `vgui2\`, `vguimatsurface\`; `particles.lib` (в SDK только библиотека) → `particles\`; `tier0`, `vstdlib`, `inputsystem`, `soundemittersystem`, `launcher` — одноимённые папки. Подмодули `ivp` (ядро физики), `lib`, `thirdparty` не скачаны — пусты.
- **Уже сверено** (совпало с найденным опытом): c30 shader API шлёт только `SetToneMappingScaleLinear` (при выключенном HDR — 1 / масштаб lightmap / 1 / 1; см. «c29–c30 принадлежат движку»); `MAX_VERTEX_FORMAT_CHANGES 128` в `gl_rsurf.cpp` — предел «127 смен формата» («Мир в картах теней»); 32 PS-константы и на SM3 (`hardwareconfig.cpp`, `shaderdevicedx8.cpp`; «Константы пиксельных шейдеров c32+»); `InitMultipleOverride` инициализаторов частиц (`particles\builtin_initializers.cpp`; «Осадки»).
