# Контент: главное меню, Steam, аддоны GMod, модели (Blender, пересборка), костюмы, руки, оружие, интро

> Общая техническая справка для любой AI-модели. Правила — `../PROJECT.md`, статус — `../CURRENT_STATUS.md`. Новые знания по теме добавлять сюда; датированные результаты сверять с текущими ресурсами и кодом.

- **Модели предметов из Blender** (2026-11-01; `hl2rpm_extras/tools/item_models/`). `python make_item_models.py [bobby_pin key_flat key_old] [--no-bake] [--no-compile] [--render]`: штампы (PIL) → `blender_items.py` в Blender 5.1 без окна (`C:\Program Files\Blender Foundation\Blender 5.1\blender.exe`; геометрия кодом в сантиметрах, Z вверх, как вещь лежит на столе; процедурные материалы: потёртости — нод Bevel, грязь — AO; запекание в один атлас, своя запись SMD с одной костью, масштаб `CM_TO_UNIT` 0.512 = 1 ед. 2.54 см × 1.3) → VTF (свой DXT из `hd_textures.py`, нормали с перенормировкой мипов, зелёный канал DirectX) и VMT → QC + коробка столкновений → `studiomdl`. Запекание трёх моделей ~6 мин на CPU. Исходники остаются в `mapsrc` рядом: `E:\XBLAH's modding tool\content\Mapbase\hl2rpm\modelsrc\hl2rpm_items\<модель>` (`.blend` открывается в Blender с материалами, PNG, SMD, QC); результат — `models/hl2rpm/items`, `materials/models/hl2rpm/items`. Модели: `bobby_pin` (шпилька-невидимка, 2.7 ед.), `key_flat` (латунный ключ с кольцом и алюминиевой биркой «№17», ключ по умолчанию), `key_old` (старый чугунный, им стал `key_storage`). **Блеск — в альфе карты нормалей**: `$pbr_roughness 0` + `$pbr_glossmask 1` (гладкость = альфа), `$pbr_metalness` на материал один — ржавчина и лак различаются альбедо и блеском; `$phong` в том же VMT — для `-nodeferred`. **Ловушки**: (1) меш из кривой приходит со слоем UV `UVMap` (параметры кривой, почти одни линии) — проверка «UV уже есть» оставляла его, и в атласе были полосы; `unwrap` убирает слой, свой UV только у шпильки (`OWN_UV`). (2) Штамп кладётся отдельным слоем UV `stamp` по детали до поворота (объектные координаты после `transform` и `join` уже другие). (3) `studiomdl` молча отбрасывает выпуклую оболочку тоньше ~0.5 ед.: `.phy` нет, в логе `collision 0 bytes` (строка ни о чём не говорит: так у любой модели, смотреть надо сам файл) — `MIN_THICK` 0.55, вещь лежит на нижней грани коробки. (4) `$staticprop` поворачивает модель на 90° вокруг Z: длинная сторона вдоль Y (карточка это учитывает, `flYawBase`). (5) В PowerShell `R` — псевдоним `Invoke-History`, для функции-помощника не годится. Просмотр модели в CK больше не ставит нижний предел дистанции под рост человека: ключ в 5 ед. был точкой. Демо на ck_test: `key_storage` — старый ключ, `key_spare` — без своей модели (в списке `ck_junk`), шпилька на ящике с хламом (ref 50).
