# Проектные справочные материалы

Все проектные `.md`-справочники собраны здесь (в едином стандарте `AI_instructions/references/`), чтобы агентам не приходилось искать документацию по разным подпапкам репозитория.

- [hl2rpm-extras.md](hl2rpm-extras.md) — карта внешних файлов в `sp/src/hl2rpm_extras/` (FGD, локализация, материалы, модели, генераторы в `tools/`).
- [tools-city27-prototype.md](tools-city27-prototype.md) — справочник по раннему greybox-прототипу `city27_test` и его скриптам (`validate_vmf.py`, `probe_bsp.py`).
- [tools-world-planner.md](tools-world-planner.md) — справочник по инструментам глобальной схемы Сити-27 (`hl2rpm_extras/tools/world/`).
- [creation-kit.md](creation-kit.md) — руководство HL2RPM Creation Kit (актуально для `hl2rpm_extras/tools/dialog_editor/` и установленного `HL2RPM Creation Kit.exe`).
- [kimodo-hl2rpm-notes.md](kimodo-hl2rpm-notes.md) — отчёт настройки Kimodo под HL2RPM: CPU-сборка, SOMA, генерация/перенос, ограничения (источник `kimodo.cpp/HL2RPM_NOTES.md`).
- [motion-bricks-hl2rpm-notes.md](motion-bricks-hl2rpm-notes.md) — отчёт MotionBricks: CPU-сборка, G1, стили и переходы, ограничения (источник `motion-bricks.cpp/HL2RPM_NOTES.md`).

> Актуальные правила проекта и таблица всех тем/навыков — [../PROJECT.md](../PROJECT.md), состояние последней работы — [../CURRENT_STATUS.md](../CURRENT_STATUS.md).
