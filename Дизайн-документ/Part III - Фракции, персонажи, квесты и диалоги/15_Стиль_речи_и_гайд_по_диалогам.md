# 15. Стиль речи и гайд по написанию диалогов

> Чтобы сотня персонажей не звучала одним голосом. Механика проверок — Part I/09.

---

## 1. Общие правила

1. **Коротко.** Реплика NPC — до 3 предложений за раз; длинные монологи только у ключевых персонажей в ключевые моменты.
2. **Реплики героя** — до 12 слов, ясные по намерению. Тон помечаем только если он неочевиден: «(солгать)», «(угрожать)».
3. **Без интернет-сленга и мемов.** Лексика «мира, застрявшего в конце 1990-х — начале 2000-х», плюс новояз Альянса.
4. **Восточная Европа — обобщённая.** Никаких отсылок к реальным современным политическим событиям, партиям и лидерам. Имена и говоры смешанные: русские, украинские, польские, белорусские, венгерские, плюс переселённые американцы.
5. **Юмор как в Valve:** сухой, ситуативный, из характера. Не ломаем драму шуткой в тот же момент.
6. **Каждая важная беседа отвечает на три вопроса:** что NPC хочет, чего боится, что скрывает.
7. **Проверки** — в квадратных скобках в начале реплики: `[Красноречие 50] ...`.
8. **Простак (АНА ≤ 3)** — искренность, а не издёвка: короткие фразы, наивная логика, иногда неожиданная мудрость. Не высмеиваем инвалидность; смеёмся над ситуацией, а не над человеком.

## 2. Голоса фракций

### Гражданская оборона
- Команды, канцелярит устава, обрывки из-за вокодера: «Гражданин. Документы. Живо». «Стоять. Руки — на стену».
- Между собой (без масок) — обычный усталый мат-полушёпот, сплетни о пайках, страх перед Надзором.
- Радиообмен — позывной + код: «Юнион-9, Дефендер-2. Имею 10-4 по сектору семь, нарушитель задержан».

**Словарь кодов ГО [М]** (звучание в духе HL2; точные значения канонических кодов Valve не раскрывала):
| Код | Значение в моде |
|---|---|
| 10-4 | Принято |
| 10-8 | На смене, в патруле |
| 10-20 | Местоположение |
| 10-78 | Нужна поддержка |
| 11-44 | Обнаружено тело |
| 11-6 | Нарушение порядка |
| 647-Е | Злостный нарушитель |
| Код 3 | Срочный выезд |
| Код 7 | Перерыв |
| «Протокол «Жнец»» | Штурм объекта Сопротивления |

### Голос Надзора (Dispatch) [К по стилю]
Холодный женский голос, рубленые формулы, триплеты-коды. Шаблон: **«Вниманию [кого]: [что случилось]. Код: [глагол], [глагол], [глагол]»**.
Примеры (наши): «Вниманию жильцов: обнаружено пассивное попустительство. Рационная норма блока сокращена». «Вниманию групп защиты: аномальная сигнатура в секторе семь. Код: найти, сохранить, доставить». (Особый код для героя: **сохранить**, не убить.)

### Солдаты Надзора и ординалы
- Грант: радиожаргон, но живой: «Контакт! Контакт! Где он, где?!», «Эхо-три ранен, мне нужна... нужна поддержка!»
- Ординал: без интонаций, без местоимений «я»: «Цель локализована. Отряду: охват. Исполнять».

### Администрация
Канцелярит и эвфемизмы: «оптимизация квартала» (облава), «добровольное переселение в сельскохозяйственные зоны» (списание), «санитарная проверка семейного положения» (Протокол), «рационная коррекция» (урезание пайков).

### Брин
Тёплый, отеческий, логичный, бесконечно рассудительный. Говорит «мы», обращается к «здравому смыслу», любит слова «инстинкт», «ответственность», «будущее», «благодетели». Никогда не угрожает прямо.

### Лямбда
По-человечески, с усталой иронией. Учёные — с терминами и оговорками («если я правильно понимаю, а я, увы, понимаю правильно»). Бойцы — коротко и по делу.

### Косари
Лозунги и рубленые приговоры: «Шкура — тот же Альянс, только с лицом». «Страх должен поменять адрес».

### Пайщики
Вежливость с угрозой, торговые метафоры: «У каждого своя доля, дорогой. Вопрос — какого размера». Кадар — по-стариковски, с прибаутками.

### Ржавые
Громко, по-рабочему, с техническими словами: «Железо не врёт. Люди врут. Железо — ржавеет, но не врёт».

### Списанные
Просто, горько, с юмором висельников: «Нас не убили. Нас просто перестали кормить». «У нас тут свобода: хочешь — голодай, хочешь — мёрзни».

### Остаток
Армейский английский у американцев (с субтитрами), ломаный русский, устав. Пирс: короткие тяжёлые фразы. Дельгадо: шуточки, испанские словечки, «Dios mío».
«Stay frosty». «Here is Remnant actual». «Сынок, я убивал людей за меньшее, чем этот вопрос».

### Вортигонты (Хор)
- Торжественно и образно. О себе — «мы». О человеке — по поступку: «тот, кто нёс сердце-камень», «Свободный человек» (о Гордоне [К]).
- Ключевые слова: **нить, узел, путь, песня, Вортэссенция, далёкие глаза**.
- Путают времена (особенно Савва без связи с Хором): «Ты пришёл. Ты приходишь. Ты придёшь».
- Никогда не врут; умалчивают — да.

### Садовники
Мягко, «по-сестрински», с ботаническими метафорами: «Ты ещё не пророс». «Мы не умираем. Мы удобряем».

### Aperture (Брандт, ядра)
Корпоративный абсурд, бодрость на фоне катастрофы. «Смотритель»: «Добро пожаловать на станцию "Борей-3"! Температура за бортом: минус сорок семь. Это на два градуса теплее нормы! Праздник!»

## 3. G-Man — правила

1. **Паузы и разрывы** внутри фраз: «Вы... оказали... неоценимую... услугу».
2. **Странные ударения** на неожиданных словах (в озвучке).
3. **Вежливость с угрозой**: «доктор», «мистер», «позвольте», «боюсь».
4. **Никогда не отвечает прямо** и никогда прямо не лжёт.
5. **Говорит о людях как о ресурсах**: «актив», «полезный», «переменная», «инвестиция».
6. **Ничего не объясняет** о себе и нанимателях (R-04).
7. Канонические обороты можно цитировать (оммаж): «Время, доктор?», «Посмотрим...», «Приготовьтесь к непредвиденным последствиям».
8. Реплик мало. G-Man — редкая специя.

## 5. Чек-лист диалога перед сдачей

- [ ] У NPC есть цель, страх и тайна?
- [ ] Есть минимум 3 тона ответа + проверки?
- [ ] Есть ветка для АНА ≤ 3 (в важных сценах)?
- [ ] Есть реакция на ГС, фракцию, Человечность, если это важно?
- [ ] Провал проверки не ломает квест?
- [ ] Указаны эффекты: XP, репутация, флаги, предметы?
- [ ] Канонический персонаж говорит своим голосом и не нарушает R-01…R-10?
