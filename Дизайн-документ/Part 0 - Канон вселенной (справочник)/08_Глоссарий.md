## 3. Термины мода [М]

| Термин | Значение |
|---|---|
| **Λ.А.М.Б.Д.А.** | Система характеристик героя (аналог S.P.E.C.I.A.L.). См. Part I. |
| **Резонанс** | Особая шкала героя: след стазиса G-Man. Открывает «Сдвиг» и «Эхо». |
| **Сдвиг** | Замедление времени: прицельный режим, аналог V.A.T.S. |
| **Эхо** | Видения прошлого в местах с «остаточным следом». |
| **Гражданский статус (ГС)** | Репутация у Альянса: от «Антигражданина» до «Лоялиста». |
| **Подозрение** | Временный «уровень розыска». |
| **Человечность** | Аналог кармы. |
| **Влияние** | Скрытая шкала: насколько герой отклонил «ожидаемый» ход событий. Её видит G-Man. |
| **Учётный браслет** | Пип-бой мода: интерфейс игрока и одновременно «ошейник» Альянса. |
| **Кредиты (кр.)** | Официальная валюта. |
| **Списание / Списанные** | Выдворение за стену / выдворенные. |
| **Последнее поколение** | Люди 18–22 лет, рождённые незадолго до поля подавления. |
| **Хранилище-2** | Проект ОАЯ по удержанию сущности G-Man. |
| **ОАЯ** | Отдел аномальных явлений Альянса в Сити-17. |
| **Пайщики** | Мафия Сити-17. |
| **Косари** | Радикальный клан Сопротивления. |
| **Вольница** | Бандитский клан Внешних земель под флагом λ. |
| **Проводники** | Ячейка Сопротивления, выводящая беженцев по каналам. |
| **Ржавые** | Банда старьёвщиков и разборщиков техники. |
| **Остаток** | Фракция ветеранов HECU и местной армии. |
| **Садовники** | Культ флоры Ксена в КЗ. |
| **Хор** | Община свободных вортигонтов Пустоши. |
| **Стервятники** | Мародёры, всегда враждебны. |
| **«Неточная наука»** | Пасхальная цепочка телепортов (США, Арктика, Ксен). |
