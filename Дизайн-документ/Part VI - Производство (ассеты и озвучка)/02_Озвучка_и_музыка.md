# Part VI. Производство
## 02. Озвучка и музыка: сейчас текст, голос — последним этапом

> План для решения «новые диалоги пока только текстом, музыка и озвучка — в самом конце». Здесь: как устроить текстовые диалоги, чтобы потом подставить голос без переделок; какую ванильную озвучку HL2 можно брать уже сейчас; как готовить финальную запись и музыку.
> Связано: Part I/09 (диалоговая система), Part III/17 (голос Надзора), Part V (все диалоги с пометками [Т] / [ВО] / [Сборка]), Part VI/01 (ассеты).

---

## 1. Принцип

1. **Каждая реплика — отдельная строка с ID**, даже если звука пока нет. Звук потом подменяется в одном месте, а сцены, скрипты и логика не трогаются.
2. **Текст — основной носитель смысла.** Субтитры включены по умолчанию для всех NPC, а не только для глухих игроков.
3. **Ванильная озвучка — там, где она точно подходит.** Не подгоняем смысл реплики под чужой голос.
4. **Герой не озвучивается никогда** (Part I/09): его реплики — варианты текста.

## 2. Текстовые диалоги в движке (схема для программиста)

### 2.1. Конвейер «немой звук + субтитр»
| Шаг | Что делаем | Где |
|---|---|---|
| 1 | Реплика получает ID: `<квест>_<сцена>_<узел>_<говорящий>`, например `MQ02_S1_N3_TAMARA` | Part V (сцены и узлы уже пронумерованы) |
| 2 | В звуковом скрипте заводится запись с этим ID. Пока голоса нет, она указывает на **немой WAV** нужной длительности | `scripts/game_sounds_dialogue_*.txt` |
| 3 | Текст реплики кладётся в файл субтитров под тем же ID | `resource/closecaption_russian.txt` → компилируется `captioncompiler` |
| 4 | Диалоговое окно и сцены (`.vcd`) ссылаются **на ID**, а не на файл | `scripts/dialogs/*.txt` (ключ `sound`), сцены Faceposer |
| 5 | Когда появится запись, меняется только путь к WAV в звуковом скрипте | — |

**Длительность немого звука:** `max(1,5 с; символы ÷ 15)` + 0,3 с паузы. Реплика из 90 символов → 6,3 с. Этого хватает прочитать субтитр, и NPC «держит» паузу как при живой речи.

### 2.2. Реплики-«барки» без диалогового окна
Короткие фразы на ходу (ГО, горожане, бой) идут через систему ответов движка (Response System: `scripts/talker/*.txt`) и предложения (`scripts/sentences.txt`). Для новых барков — тот же немой звук и субтитр. Для ванильных — оригинальные группы (§4).

### 2.3. Без лип-синка, пока нет голоса
- Немой звук не двигает губы. Пока голоса нет, лицо NPC играет **эмоцию** из сцены: флексы улыбки, хмурости, моргание. Так текст не выглядит «мёртвым».
- После записи: извлечение фонем (Faceposer, phoneme extractor) → лип-синк автоматически.

## 3. Где лежит ванильная озвучка

| Что | Папка / группа | Примечание |
|---|---|---|
| Горожане и повстанцы | `sound/vo/npc/male01/`, `sound/vo/npc/female01/` | Приветствия, согласие, отказ, вопросы и ответы в ожидании, тревоги, боль |
| Гражданская оборона | `sound/npc/metropolice/vo/` + группы предложений `METROPOLICE_*` | Короткие команды, коды, тревоги. Щелчки рации — отдельные звуки включения и выключения |
| Солдаты Надзора | `sound/npc/combine_soldier/vo/` + группы `COMBINE_*` | Склеиваются из фрагментов |
| Голос Надзора: город | `sound/npc/overwatch/cityvoice/` | Объявления громкоговорителей |
| Голос Надзора: рация | `sound/npc/overwatch/radiovoice/` | Фрагменты для сборки новых фраз (§5) |
| Вортигонты | `sound/vo/npc/vortigaunt/` + группы `VORT_*` | Инопланетная речь, звуки атаки и лечения, английские фразы |
| Брин-касты | `sound/vo/breencast/` | Обращения Брина |
| Канонические персонажи | `sound/vo/…` по главам HL2, Episode One, Episode Two | Только канонические строки (§4.3) |

**Русский дубляж.** HL2 и эпизоды в Steam выходили с официальной русской озвучкой. Если мод на русском, ванильные реплики берутся из русской версии: имена файлов те же, отличается языковой пакет. Перед записью проверить, какие игры серии в Steam имеют русскую озвучку, а какие только субтитры.

## 4. Что из ванили брать и что нельзя

### 4.1. Можно брать как есть
| Ситуация в моде | Ванильный источник | Комментарий |
|---|---|---|
| ГО: проверка, угрозы, «проходи», «подними банку» | `METROPOLICE_IDLE_HARASS_PLAYER`, `_MOVE_ALONG_*`, `_FREEZE`; реплики сцены «Pick up that can» | Сцена SQ-01 почти целиком на ванильных репликах |
| ГО: болтовня патруля, проверки «всё чисто» | `METROPOLICE_IDLE*`, `_IDLE_QUEST/_ANSWER`, `_IDLE_CHECK/_CLEAR` | Фон города |
| ГО: тревога, погоня, потеря цели, раненые | `_GO_ALERT`, `_HES_RUNNING`, `_LOST_*`, `_MAN_DOWN`, `_LAST_OF_SQUAD`, `_PAIN*`, `_DIE` | Бой и розыск |
| Солдаты Надзора в бою | Все группы `COMBINE_*` | Предварительно прослушать `_PLAYER_DEAD`, `_MONST_PLAYER`: исключить фрагменты с именем Фримена, если попадутся |
| Голос Надзора в городе | `cityvoice`: объявления, совпадающие с Part III/17 (№ 1–5, № 6–10 после сверки) | Помечено в Part III/17 и Part V как [К] / [К?] |
| Горожане: приветствия, согласие, отказ, «извините», «берегись», «хедкрабы!», «ГО!», боль, вопросы и ответы в ожидании | `vo/npc/male01`, `female01` | Фон и массовка. Фразы-вопросы о жизни при Альянсе подходят к любому акту |
| Брин-каст «Добро пожаловать в Сити-17» | `vo/breencast` | **Пролог**: канонически крутится для всех прибывающих |
| Брин-каст об инстинкте размножения | `vo/breencast` | **Акт II**: прямо поддерживает тему Протокола семейного контроля (D-07) |
| Вортигонты: инопланетная речь, хоровое пение, лечение, атака | `VORT_*`, `vo/npc/vortigaunt` | Хор, Савва, сцены у каменоломни |
| Отец Григорий в бою | `vo/ravenholm` | Боевые выкрики и смех |
| Сирены, рация, гул Цитадели, отсчёт до сингулярности | Ванильные звуки и `cityvoice` | Акт IV, Цитадель |

### 4.2. Нельзя брать
| Что | Почему |
|---|---|
| Любые реплики с «Gordon», «Freeman», «Doctor Freeman», «doc», «hey doc», «it's him», «you're him» | Герой — не Гордон (R-01) |
| Реплики вортигонтов о «Свободном человеке» в адрес героя | То же. Вортигонты в моде обращаются к герою «тот, кто нёс сердце-камень» |
| Брин-касты, где упоминается Фримен или восстание, — **до** Акта III–IV | Хронология (Part IV/09) |
| G-Man | Почти все его реплики обращены к Фримену. Новые фразы — только новая запись |
| Голоса Барни, Аликс, Илая, Кляйнера, Моссман для **новых** фраз | Нельзя склеивать новые смыслы из чужих фраз канонических героев. Только их канонические строки в канонический момент |
| Музыка и голоса из Half-Life: Alyx, Black Mesa, других игр | Права (Part VI/01, §14) |

### 4.3. Канонические персонажи: правило
- Их **канонические** реплики допустимы только там, где мод показывает канонический момент: эфир Кляйнера при эвакуации (Episode One), сцены у Нова Проспекта, бой Григория.
- Все **новые** реплики канонических персонажей в моде — **[Т]** (только текст), а при финальной озвучке — новая запись голосом, похожим по тембру. Подражание голосу реальных актёров с помощью ИИ без их согласия — **нельзя** (§6.3).

## 5. Голос Надзора: сборка из фрагментов

Ванильный голос Надзора сам склеен из коротких фрагментов: обращения, слова-коды, числа, адреса. Поэтому многие **новые** объявления мода можно собрать из ванильных кусков без новой записи.

| Шаг | Что делаем |
|---|---|
| 1 | Составить словарь фрагментов `radiovoice` и `cityvoice`: слово → файл (обращения, глаголы кодов, существительные, цифры 0–9, «блок», «сектор», «зона», позывные) |
| 2 | Для реплики с пометкой **[Сборка]** (Part III/17, §10) выписать цепочку фрагментов |
| 3 | Склеить в звуковом редакторе с паузами 80–150 мс. Если в моде английский оригинал голоса — склеивать английские фрагменты; если русская версия — фрагменты русского дубляжа |
| 4 | Добавить радиофильтр: щелчок включения, полосовой фильтр 300–3 400 Гц, лёгкий перегруз, писк и треск выключения |

Реплики, которые не собираются (новые слова: «Протокол семейного контроля», «аномальная сигнатура», «Носитель»), помечены **[Новая]** и ждут финальной записи.

## 6. Финальная озвучка (последний этап)

### 6.1. Объём (оценка)
| Блок | Говорящие | Реплик NPC (оценка) |
|---|---|---|
| Главный квест | ~35 | ~2 500 |
| Квесты фракций | ~45 | ~4 000 |
| Побочные квесты | ~50 | ~2 500 |
| Спутники | 6 | ~1 500 |
| Генерики, торговцы, наставники, барки | ~30 голосов массовки | ~3 000 |
| Голос Надзора (новые [Новая]) | 1 | ~150 |
| **Итого** | ~150 ролей, ~40 актёров с дублированием | **~13 000 реплик** |

Точные числа — после подсчёта строк в Part V (ID реплик).

### 6.2. Порядок записи
1. Голос Надзора [Новая] и новые барки ГО — их слышно постоянно.
2. Главный квест: Квятковский, Тамара Ильинична, «Клинок», Лейла, Кадар, Брин (новые Брин-касты).
3. Спутники.
4. Квестодатели фракций.
5. Побочные квесты.
6. Массовка.

### 6.3. Кастинг и правила
- **Акценты по происхождению** (Part 0/09): Квятковский — польский, Кадар — венгерский, Кофи Менса — ганский английский и т.д. Актёр либо носитель, либо репетирует с носителем. Карикатура запрещена.
- **ИИ-голоса:** только синтетические модели с лицензией на коммерческое и некоммерческое использование, без клонирования голосов реальных людей без их письменного согласия. Особенно это касается голосов из серии (Эллен Маклейн, Майкл Шапиро, Роберт Гийом и др.).
- **Формат записи:** WAV, 44,1 кГц, 16 бит, моно; запас тишины 0,2 с в начале и конце; одинаковая громкость реплик одного персонажа.
- **Обработка:** ГО — вокодер и радиофильтр; солдаты Надзора — сильнее; ординалы — «машинный» тембр без эмоций; вортигонты — низкий тембр с реверберацией; G-Man — сухо, близко к микрофону, неожиданные паузы (Part III/15).

## 7. Музыка

### 7.1. Что можно взять
| Источник | Можно ли |
|---|---|
| Саундтрек HL2, Episode One, Episode Two (Келли Бейли) | **Да**: это контент HL2, подключается из установленной игры |
| Саундтрек Half-Life: Alyx (Майк Моразки) | **Нет** |
| Музыка Black Mesa, других модов и игр | **Нет** (без лицензии) |
| Библиотеки «royalty-free» | Да, если лицензия разрешает использование в играх и модах; хранить копию лицензии |
| Заказная музыка | Да, с договором о правах |

## 8. Чек-лист перед финальной озвучкой

- [ ] У каждой реплики в Part V есть ID и строка в субтитрах.
- [ ] Все реплики [ВО] прослушаны: нет имени Фримена, смысл совпадает.
- [ ] Реплики [Сборка] собраны и прошли радиофильтр.
- [ ] Для каждого персонажа есть карточка голоса: возраст, происхождение, акцент, темп, 3 эталонные реплики.
- [ ] Права на музыку и голоса оформлены письменно.
