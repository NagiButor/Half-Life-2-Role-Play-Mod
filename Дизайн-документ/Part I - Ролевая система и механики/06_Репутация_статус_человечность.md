# 06. Репутация, Гражданский статус, Подозрение, Человечность, Резонанс, Влияние

> Шесть «социально-сюжетных» шкал. Сейчас в коде одна общая репутация (`CQuestSystem::GetReputation`). Её нужно превратить в набор шкал по фракциям (см. файл 16).

| Шкала | Диапазон | Видна игроку | Что отражает |
|---|---|---|---|
| Репутация фракций (×10) | −100…+100 | Да (браслет → «Отношения») | Как к герою относится каждая сила |
| Гражданский статус (ГС) | −100…+100 | Да (на браслете, всегда) | Статус в глазах Альянса |
| Подозрение | 0…100 | Да (значок «глаз» в HUD) | Сиюминутное внимание ГО: «уровень розыска» |
| Человечность | 0…100 | Да (браслет → «Личное») | Аналог кармы |
| Резонанс | 0…100 | Да (после Акта I) | След стазиса G-Man |
| Влияние | 0…100 | **Нет** | Насколько герой отклонил «ожидаемый» ход событий |

## 1. Репутация фракций

### 1.1. Фракции с репутацией
| Код | Фракция | Старт | Где живёт |
|---|---|---|---|
| `lambda` | **Лямбда** (основное Сопротивление; включает НМО и Белый Лес) | 0 | Город (подполье), BME, Побережье, Внешние земли |
| `ferrymen` | **Проводники** (выводят беженцев по каналам) | 0 | Каналы, Пустошь |
| `reapers` | **Косари** (радикальный клан) | 0 | Промзона, Старый город |
| `freefolk` | **Вольница** (бандитский клан под флагом λ) | −10 | Внешние земли |
| `chorus` | **Хор** (свободные вортигонты) | 0 | Пустошь, Побережье |
| `shareholders` | **Пайщики** (мафия) | 0 | Старый город, каналы, корабельное кладбище |
| `rust` | **Ржавые** (старьёвщики-разборщики) | 0 | Промзона, свалки |
| `writtenoff` | **Списанные** (выдворенные за стену) | 0 | Пустошь |
| `remnant` | **Остаток** (ветераны HECU и местной армии) | −10 | Внешние земли |
| `gardeners` | **Садовники** (культ Ксена) | −20 | Карантинная зона |
| — | **Стервятники** (мародёры) | всегда враги | Пустошь, Внешние земли |

Альянс как целое оценивается через **Гражданский статус** (раздел 2). Внутри Альянса у героя бывают **служебные линии**: звание в ГО, доверие Администрации, разряд рабочего. Это прогресс по квестам, а не репутация.

### 1.2. Уровни отношения
| Значение | Уровень | Что происходит |
|---|---|---|
| ≤ −60 | **Враг** | Атакуют при встрече; торговли нет; за голову героя может быть награда |
| −59…−25 | **Неприязнь** | Не дают квестов, цены +25%, в лагерь не пускают или пускают под конвоем |
| −24…+24 | **Нейтралитет** | Обычные отношения, начальные квесты |
| +25…+59 | **Признание** | Квесты среднего уровня, цены −10%, убежище, фракционный перк 1-го уровня |
| +60…+100 | **Союзник** | Финальные квесты линии, цены −20%, уникальное снаряжение, перк-вершина, участие фракции в финале героя |

### 1.3. Как меняется репутация
| Действие | Изменение |
|---|---|
| Мелкая помощь, подарок, разговор с верной проверкой | +2…+5 |
| Выполненный квест фракции (T2–T3) | +8…+15 |
| Ключевой квест фракции (T4) | +20…+30 |
| Кража у фракции (если заметили) | −5 |
| Нападение на члена фракции | −10 |
| Убийство члена фракции (если стало известно) | −15 (лидера −40) |
| Провал квеста по вине героя | −5…−15 |
| Предательство (сдать фракцию врагу) | −40…−60, обычно мгновенно «Враг» |
| Помощь врагу фракции (если стало известно) | −3…−10 |

### 1.4. Огласка
Каждый поступок имеет **огласку**:
- **Тайно** — никто не узнал: изменений нет (кроме Человечности и Влияния, им свидетели не нужны).
- **Слухи** — узнали через время: изменение ×0,5 применяется при следующем визите героя к фракции.
- **Открыто** — свидетели из фракции или громкое событие: полное изменение сразу.

### 1.5. Отношения фракций между собой
`++` союз · `+` дружба · `0` нейтралитет · `−` напряжение · `−−` война

|  | Альянс | Лямбда | Провод. | Косари | Вольница | Хор | Пайщики | Ржавые | Списан. | Остаток | Садовн. |
|---|---|---|---|---|---|---|---|---|---|---|---|
| **Альянс** | | −− | −− | −− | −− | −− | − (подкуп) | − | −− | −− | −− |
| **Лямбда** | −− | | ++ | − | −− | ++ | 0 | + | + | + | −− |
| **Проводники** | −− | ++ | | − | −− | + | − | 0 | ++ | + | − |
| **Косари** | −− | − | − | | 0 | 0 | − | 0 | 0 | 0 | −− |
| **Вольница** | −− | −− | −− | 0 | | − | + (сбыт) | − | −− | −− | 0 |
| **Хор** | −− | ++ | + | 0 | − | | 0 | 0 | + | 0 | − |
| **Пайщики** | − | 0 | − | − | + | 0 | | −− | 0 | 0 | 0 |
| **Ржавые** | − | + | 0 | 0 | − | 0 | −− | | + | + | 0 |
| **Списанные** | −− | + | ++ | 0 | −− | + | 0 | + | | + | − |
| **Остаток** | −− | + | + | 0 | −− | 0 | 0 | + | + | | −− |
| **Садовники** | −− | −− | − | −− | 0 | − | 0 | 0 | − | −− | |

**Эхо-изменения (рябь).** Крупные поступки (от ±15) задевают отношения с союзниками и врагами фракции:
- союзник `++` получает **40%** изменения, друг `+` — **20%**;
- враг `−−` получает **−40%**, напряжённая `−` — **−20%**.

Пример: квест на +20 Лямбде даёт +8 Проводникам, +8 Хору, −4 Косарям. Если это стало известно Альянсу — ещё и ГС −8.

## 2. Гражданский статус (ГС) — репутация у Альянса

Канонический оборот голоса Надзора *«подтвердите свой гражданский статус»* становится полноценной системой.

### 2.1. Уровни
| Значение | Статус | Последствия |
|---|---|---|
| ≤ −75 | **Антигражданин** | Огонь на поражение ГО и Надзора по всему городу; объявления голоса Надзора о герое; награда за голову |
| −74…−40 | **Злостный нарушитель** | Арест при встрече; сопротивление → «Антигражданин»; пайков нет |
| −39…−15 | **Под наблюдением** | Проверка документов при каждой встрече с ГО; пайки −3/нед.; нет доступа в Квартал лояльности; сканеры следят дольше |
| −14…+19 | **Гражданин** | Обычная жизнь: 7 пайков и 7 банок воды в неделю, базовые работы |
| +20…+49 | **Благонадёжный** | Проверки реже (×0,5), пайки +3/нед., доступ к работам ИК и Администрации, взятки ГО −20% |
| +50…+100 | **Лоялист** | «Лоялистская карта»: Квартал лояльности, квартира, магазины Альянса с «улучшенным пайком» и лекарствами, ГО закрывает глаза на нарушения кат. I, пропуск к Администрации |

**Пролог:** до получения постоянных документов (MQ-02) у героя статус **«Временный пропуск»**: как «Гражданин», но любая проверка ГО — с вопросами, а работы только разовые.

### 2.2. Как растёт и падает ГС
| Действие | ГС |
|---|---|
| Отработанная смена | +1 (не больше +8 за акт с работ) |
| Подчинение приказу ГО, «Подберите банку» | +1 (с перком PK-02) |
| Добровольный взнос в «Фонд Благодетелей» | +1 за 50 кр. (не больше +10 за акт) |
| Донос на нарушителя (подтверждённый) | +3…+10 (Человечность −2…−5) |
| Квест Администрации или ГО | +5…+20 |
| Нарушения кат. I / II / III / IV | −2…−5 / −10…−20 / −30…−40 / → «Антигражданин» |
| Пойман с самиздатом / запрещённой книгой | −5 / −10 |
| Связь с Сопротивлением доказана | −40 |

### 2.3. Динамика по актам
С каждым актом Альянс строже: **пороги сдвигаются**.
- Акт II: «Под наблюдением» начинается с −10 (было −15), бонусы «Благонадёжного» требуют +25.
- Акт III: военное положение — проверки при любом ГС ниже «Лоялиста».
- Акт IV: ГС теряет смысл в повстанческих кварталах. В подконтрольных Альянсу секторах любой гражданин с оружием — цель.

## 3. Подозрение — «уровень розыска»

Сиюминутное внимание ГО и сканеров. В отличие от ГС, Подозрение **спадает со временем**.

| Значение | Уровень | Реакция |
|---|---|---|
| 0–24 | Спокойно | — |
| 25–49 | **Внимание** | ГО может остановить для проверки документов |
| 50–74 | **Досмотр** | ГО остановит и обыщет инвентарь (контрабанда → преступление) |
| 75–99 | **Задержание** | Попытка ареста; бегство → 100 |
| 100 | **Тревога** | Бой, голос Надзора объявляет код, подкрепление, сканеры |

### Источники Подозрения
| Действие в зоне контроля Альянса | Подозрение |
|---|---|
| Бег рядом с ГО | +2/с |
| Оружие в руках | +20/с (почти мгновенная тревога) |
| Нахождение в запретной зоне | +5/с |
| Нарушение комендантского часа (замечен) | +25 |
| Фото сканера во время нарушения | +15 (и запись в базу) |
| Фото сканера просто так при ГС «Под наблюдением» | +5 |
| Рядом с местом преступления, когда прибыла ГО | +10 |
| Резонанс ≥ 40 рядом с резонансным сканером ОАЯ | +10 (кроме пути Альянса) |
| Неудачная ложь ГО | +15 |
| Повстанческая броня или повязка λ | Мгновенно 100 |

**Спад:** −5 в игровую минуту вне поля зрения ГО и сканеров. Множители: ГС «Благонадёжный» ×1,5, «Лоялист» ×2; «Под наблюдением» ×0,5. В толпе с перком «Свой в толпе» ×2. Сон дома — до 0.

### Оружие в городе
Гражданам **запрещено** носить оружие ([К] по духу HL2: граждане безоружны).
- **В руках** — см. таблицу выше.
- **В инвентаре** — не видно, пока нет **досмотра** (Подозрение ≥ 50) или **КПП со сканером-рамкой**. Рамка находит металл: оружие, патроны, детали.
- **Разрешено**: монтировка, гаечный ключ и прочие **рабочие инструменты** при наличии наряда рабочего; электродубинка и пистолет — у ГО.
- Как пронести оружие через КПП: обход (каналы, крыши), взятка, проверка `[Торговля/Скрытность ≥ уровня поста]`, тайник по ту сторону, перк «Удостоверение» (ГО), хакинг рамки.

### Маскировка
| Одежда | Эффект | Раскрытие |
|---|---|---|
| Гражданская роба | Обычный гражданин | — |
| Комбинезон рабочего / хазмат ИК | Пропуск на стройки, в КЗ, в промзону; рабочий инструмент разрешён | Проверка наряда: Красноречие или поддельный наряд |
| Форма и маска ГО | ГО и Надзор считают «юнитом» | Проверка жетона: (Скрытность + 5×АВТ) против бдительности (ГО 40, офицер 60, ординал 80, сканер ОАЯ 90). Странное поведение (бег от патруля, грабёж, стрельба по своим) — мгновенно |
| Броня Надзора | Надзор считает своим только с имплантом «Биосигнал» | Иначе вблизи раскрывают за 3 с |
| Повстанческая одежда | Повстанцы доверяют, ГО стреляет | — |

## 4. Человечность (0–100)

Старт **50**. Мера человеческого в герое: сострадания, чести, способности остаться собой.

| Значение | Уровень | Эффекты |
|---|---|---|
| 0–19 | **Пустой** | Вортигонты отказываются общаться; Савва уходит; доступ к тёмным перкам; часть концовок закрыта («Свободный человек») |
| 20–39 | **Чёрствый** | Простые люди боятся; Пайщики и Вольница уважают; −5% к ценам у бандитов |
| 40–60 | **Человек** | Норма |
| 61–80 | **Сострадательный** | Списанные и беженцы помогают бесплатно; Хор +10 при знакомстве |
| 81–100 | **Праведный** | Особые реплики у Григория, Агаты, вортигонтов; лучшие варианты эпилога для спасённых |

| Действие | Человечность |
|---|---|
| Спасти невинного (вне квестовой награды) | +2…+5 |
| Отпустить сдавшегося врага | +2 |
| Отдать еду или лекарство нуждающемуся | +1…+3 |
| Освободить раба-вортигонта | +5 |
| Убить безоружного / сдавшегося | −5 |
| Убить невинного гражданина | −10 |
| Донести на соседа | −2…−5 |
| Пытка, «стимулятор правды» на допросе (на пути ГО) | −5 |
| Имплант | −3 (Биосигнал −5) |
| ☠ «Последний паёк» (съесть человека) | −5 |
| Трансчеловеческая интеграция | Потолок 20 |

## 5. Резонанс (0–100)

Описание способностей — в файле 02. Как растёт и падает:

| Событие | Резонанс |
|---|---|
| Сюжетные вехи (Якорь, калибровка, Black Mesa, Ксен, встречи с G-Man) | +5…+15 |
| Контакт с кристаллами Ксена, телепорт, споровая буря | +1…+3 |
| Ритуал Хора «Песнь» (видения) | +5 |
| Использование «Эха» | +1 |
| Черта «Тень костюма» | ×1,5 ко всему росту |
| Ритуал «Заземление» у Хора | −10 |

## 6. Влияние (0–100, скрыто)

Не «добро/зло», а **масштаб вмешательства**. G-Man оценивает актив по тому, насколько тот **предсказуем**.

| Событие | Влияние |
|---|---|
| Решение главного квеста, меняющее судьбу фракции (уничтожить, возвысить) | +8…+15 |
| Убийство ключевого NPC мода, который «должен был жить» по плану G-Man (помечены в Part III) | +10 |
| Спасение ключевого NPC, который «должен был погибнуть» | +5 |
| Каждое использование «Застывшего мига» | +2 |
| Попытка поймать G-Man в Хранилище-2 | +25 |
| Уничтожение Хранилища-2 | +10 |
| Передача Хранилища-2 Альянсу | +15 |
| Принятие «Контракта» в Акте III | −20 (стал «предсказуем») |

**В финале** (подробно — Part IV):
- Влияние < 40 → G-Man предлагает **«Контракт»** или отпускает («Посмотрим, как вы распорядитесь... свободой»).
- 40–69 → обычный выбор у G-Man.
- ≥ 70 → G-Man объявляет **«Изъятие»** («...чрезмерное влияние на... исход»). Отменить можно только защитой Хора: перк PK-71 или репутация Хора «Союзник» + Резонанс ≥ 50. Вортигонты **заслоняют** героя, как в начале Episode One.
