# 14. Интерфейс

> Принцип: **HUD как в HL2** (минимум цифр по углам), а вся «ролевая» глубина — в **учётном браслете** (аналог Пип-боя). Браслет — диегетический предмет [Д D-13]: Альянс выдаёт его на вокзале как средство учёта, а значит, и **слежки**.

---

## 1. HUD

```
┌────────────────────────────────────────────────────────────────────┐
│      ◄─ С ── ✦ ──── В ── ● ── Ю ──── З ─►   (компас, метки)        │
│                                                     👁 ПОДОЗРЕНИЕ  │
│                                                     ▓▓▓░░░░ 38     │
│                                                                    │
│                                                                    │
│                              +                                     │
│                                                                    │
│ ✚ 100   ⛨ 0                                   18 │ 54   9 мм       │
│ [яд][споры: 1][травма: нога]          Сдвиг ▓▓▓▓▓▓░░    ◈ λ-тайник │
└────────────────────────────────────────────────────────────────────┘
```

| Элемент | Описание |
|---|---|
| **Компас** (вверху, тонкая полоса) | Стороны света, метки квестов, угроз (по Бдительности), тайников λ (с перком), явлений Резонанса |
| **Здоровье / броня-щит** | Стиль HL2: оранжевые цифры слева внизу; щит виден только в HEV/PCV/броне Надзора |
| **Патроны** | Стиль HL2 справа внизу |
| **Подозрение** | Иконка «глаз» + полоса; появляется только в зонах контроля и при значении > 0 |
| **Состояния** | Мелкие иконки: яд, радиация, споры (стадия), травмы, опьянение |
| **Очки Сдвига** | Полоса появляется после MQ-05, видна при неполном запасе |
| **Всплывающие уведомления** | «+25 XP», «Лямбда ↑», «Гражданский статус ↓», «Новая локация: Старый город» — короткие строки в левом верхнем углу, как подсказки HL2 |
| **В HEV** | Добавляется HUD костюма (оранжевые рамки, «голос» HEV: «Обнаружена радиация»). Пасхалка: голос костюма узнаёт героя: «С возвращением, доктор...» (Акт III) |
| **В маске ГО** | Тонкий синий интерфейс маски: номера юнитов, коды, подсветка «нарушителей» |

## 2. Учётный браслет (главное меню)

Открывается клавишей (поднять руку — анимация в первом лице). Пять вкладок:

### 2.1. «Гражданин» (статус)
- **Λ.А.М.Б.Д.А.** — шесть характеристик с описаниями.
- **Навыки** — значения, теги, бонусы.
- **Перки, черты, импланты**.
- **Состояния** — травмы, радиация, споры, зависимости.
- **Гражданский статус** — официальная «карточка гражданина»: номер, статус, нормы выдачи, **записи о нарушениях**.
- **Личное** (после MQ-05): Резонанс, Человечность. Влияние скрыто.

### 2.2. «Имущество» (инвентарь)
- **Уже реализован** (`vgui_inventorypanel`): вес в кг, перегруз, предметы, патроны.
- Добавить: категории (оружие / броня / медицина / еда / документы / ключи / записи / прочее), сравнение характеристик, метку **«контрабанда»** (красная рамка), состояние предмета, кредиты и смола в шапке.

### 2.3. «Данные»
- **Задания** — активные / выполненные / проваленные; этапы; кнопка «отслеживать» (метка на компасе). Уже есть `quest_system`; нужно добавить категории (главное, фракции, побочные, спутники) и пометку **«исчезнет при смене акта»**.
- **Заметки** — прочитанные записки, терминалы, аудиозаписи (с текстом).
- **Отношения** — репутации фракций с уровнями; список знакомых NPC с отношением (как «карточки»).
- **Карта** — региональная и секторная; метки открытых локаций; быстрое перемещение.

### 2.4. «Пайки»
- Еженедельная норма по ГС, ближайший раздаточный пункт и время раздачи, долги и штрафы.
- На взломанном браслете (путь Лямбды) вкладка показывает «⚠ отключено» и заменяется вкладкой **«Частота λ»**.

### 2.5. «Радио»
- «Голос Города» (официальная станция: Брин-касты, объявления, музыка Альянса).
- После квестов: **частота λ** (Лямбда; голос Кляйнера в Акте IV, ср. его эфир в Episode One), **волна «Остатка»** (английские позывные), **канал ГО** (если украден жетон или путь ГО) — подслушивание рейдов.

### Браслет как «ошейник»
| Состояние браслета | Плюсы | Минусы |
|---|---|---|
| Штатный | Пайки, станции здоровья, проезд, двери по уровню | ГО знает, где герой был: при расследованиях Подозрение растёт быстрее, если герой был рядом |
| **Взломанный** (Лямбда, Хакинг 50) | Нет слежки, частота λ | Пайки и станции только через хакинг; при проверке ГО видит «сбой» → `[Ложь 50]` |
| **Снятый** | Полная свобода за стеной | В городе — мгновенно «Под наблюдением» при любой проверке |

## 3. Прочие экраны

| Экран | Описание |
|---|---|
| **Диалог** | Уже есть (`dialog_ui`): реплика NPC сверху/по центру, варианты снизу. Добавить: цвет проверок (зелёный/красный), иконки (λ, ГС, перк), значок «выход». Субтитры обязательны. |
| **Торговля** | Две колонки (использовать готовую разметку `Loot Left/Right`): товары торговца / герой, касса, вес, итог сделки |
| **Новый уровень** | Распределение очков навыков → выбор перка (список с фильтром «доступные», описания с цитатой-«флейвором») |
| **Отмычка / мультитул** | Полноэкранные мини-игры (файл 10) |
| **Анкета гражданина** | Экран создания персонажа в конце теста профпригодности (Пролог) |
| **Колесо спутника** | Радиальное меню команд (файл 13) |
| **Ожидание / сон** | Часы и выбор времени; при комендантском часе — предупреждение |
| **Слайды эпилога** | Чёрно-белые «плакатные» изображения в стиле пропаганды Альянса для лояльных концовок и «полароидов» Сопротивления для остальных + закадровый голос |

## 4. Звуковой интерфейс
- Уведомления — короткие звуки HL2: «пиканье» браслета, голос Надзора для статуса («Гражданский статус пересмотрен»).
- Повышение уровня — мягкий синтезаторный аккорд в духе саундтрека Келли Бэйли, без фанфар.
- Подозрение 75+ — нарастающий фоновый гул и шаги ГО в рации.
