# 10. Взлом, хакинг и доступ

> Закрытые двери — главный «язык» ролевой системы: за каждой запертой дверью сидит вопрос «каким навыком ты её откроешь?». Правило: **у любой двери с ценным содержимым минимум два ключа**: навык и альтернатива (предмет, маршрут, человек).

---

## 1. Механические замки (навык Взлом)

### Мини-игра «Отмычка»
- Вид как в Fallout 3/NV: отмычка в скважине, поворот «натяжителем». Узнаваемо и быстро.
- Тиры и пороги — как в файле 03: 0 / 25 / 50 / 75 / 100.
- **Ниже порога** замок нельзя даже пробовать: в интерфейсе пишется «Требуется Взлом 50».
- Расходник — **отмычки** (8 кр., крафт из проволоки). Ломаются при перегрузке. Перк «Связка ключей» −50% поломок.
- **Шум.** Каждая сломанная отмычка — тихий щелчок. В охраняемой зоне ГО может услышать (Подозрение +5).

### Силовое вскрытие
| Способ | Проверка | Цена |
|---|---|---|
| Монтировкой | `[Мощь 5/7/9]` по тиру (только до «Сложного») | Громко: Подозрение +20 в зоне контроля; содержимое может пострадать (хрупкие предметы) |
| Гравипушкой (прототип) | Только решётки и лёгкие двери | Тихо |
| Взрывчаткой | Любой замок с дверью | Очень громко; часть лута уничтожена |
| Ключ | Найден, украден, получен по квесту | Тихо, без проверки |

## 2. Устройства Альянса (навык Хакинг + мультитул)

Хакинг устройств Альянса требует **мультитула** [К: инструмент Аликс в Alyx]. Его выдаёт Лямбда (LM-01), продают Пайщики, его можно собрать (Ремонт 35 + детали). Улучшенные версии **Мк II / Мк III** дают **+10 / +20** к эффективному Хакингу и по одной «бесплатной» повторной попытке на устройство.

### Мини-игры (дань Alyx)
| Мини-игра | Устройства | Суть |
|---|---|---|
| **«Трасса импульса»** | Силовые поля, двери Альянса, мосты | Повернуть сегменты, чтобы импульс прошёл от входа к выходу, минуя «ловушки» |
| **«Сфера»** | Замки фабрикаторов, ящики ИК, сейфы ОАЯ | Вести курсором по голографической сфере, по вибрации и звуку находить скрытые узлы |
| **«Частота»** | Сканеры, турели, роллермины, камеры | Совместить волну сигнала с эталоном тремя регуляторами за ограниченное время |
| **«Глифы»** | Терминалы Альянса, узлы Нексуса | Запомнить и повторить последовательность глифов; с тиром растёт длина |

### Последствия провала
| Устройство | Провал |
|---|---|
| Двери, поля | Блокировка на 1 игровой час |
| Турели | Турель «просыпается» враждебной |
| Сканеры, камеры | Сигнал в участок → патруль через 2 мин, Подозрение +25 |
| Терминалы ГО и Администрации | «Попытка несанкционированного доступа»: запись на учётную карту (ст. II-6), если не стёрта |
| Устройства ОАЯ | Резонансный сканер вылетает к месту взлома |

### Что даёт хакинг (примеры)
| Цель | Результат |
|---|---|
| Раздатчик пайков | +3 пайка (раз в сутки на автомат) |
| Станция здоровья | Лечение без учётной карты |
| Турель | Выключить или, с перком PK-34, сделать союзной |
| Сканер | Сбить, «ослепить» или, с перком PK-35, сделать разведчиком |
| Терминал участка | Стереть запись, узнать о рейдах, найти досье |
| Камера двора | Выключить на 10 минут |
| Фабрикатор | Доступ к улучшениям оружия за смолу |
| КПП-рамка | Пронести металл без досмотра |
| Мост Альянса, шлюз | Открыть путь аэроглиссеру |

## 3. Человеческие компьютеры (Хакинг без мультитула)

Довоенные и подпольные терминалы (Black Mesa, НИИ, Пайщики, Остаток) взламываются **подбором пароля** в духе Fallout: экран «мусора» с вариантами слов, подсказка «совпадение букв». Слова **русские** (на терминалах Black Mesa и Aperture — английские). Тиры меняют длину слов и число попыток.

## 4. Уровни доступа (документы)

| Уровень | Документ | Открывает |
|---|---|---|
| 0 | Временный пропуск | Вокзал, Квартал 7, раздача |
| 1 | Учётная карта гражданина | Жилые кварталы, Старый город, промзона (проходные), больница |
| 2 | Наряд рабочего / хазмат-пропуск ИК | Стройки, депо, КПП Карантинной зоны, склады |
| 3 | Пропуск служащего Администрации | Административный центр, архив (частично), Квартал лояльности |
| 4 | Жетон ГО | Участки, оружейные (с рангом), КПП, крыши, тоннели ГО |
| 5 | Биосигнал Надзора | Нексус, ворота Цитадели (нижние уровни), аванпосты |
| 6 | Резонансный ключ ОАЯ | Лаборатории ОАЯ, Хранилище-2 (Акт IV) |

### Как получить доступ «не по праву»
- **Подделки** у Пайщиков (уровни 1–3), **украденные** жетоны и карты (временные — аннулируются через 1–2 игровых дня).
- **Маскировка** (файл 06) + проверка при встрече.
- **Сопровождение**: Виктор-6 проводит героя по жетону, Ветрова — по наряду ИК.
- **Хакинг** считывателя (тир = уровень доступа × 15 + 25).

## 5. Альтернативные маршруты (обязательный слой уровней)

Каждый закрытый объект должен иметь минимум **один** из обходов:

| Обход | Навык / средство | Пример |
|---|---|---|
| Вентиляция | Ловкость, Мощь (решётка) | Участок ГО → архив |
| Крыши | Ловкость, Бдительность (найти путь) | Как погоня в Point Insertion |
| Каналы и коллекторы | Выживание, «Канальная крыса» | Под промзоной, под Администрацией |
| Гравипушка | Физика объектов | Сложить мостик, снять решётку |
| Спутники | Щелчок пролетает в вентиляцию и открывает дверь изнутри; Тишина вскрывает замок; Виктор-6 «по жетону» | |
| Люди | Подкуп сторожа, свидание с охранником, «ты тут работаешь?» | |
| Время | Ночью охраны меньше, днём толпа скрывает | |

## 6. Ловушки

| Ловушка | Где | Обнаружение | Обезвреживание |
|---|---|---|---|
| Растяжка с гранатой | Убежища повстанцев, Остаток | БДИ 5 / «Сапёр» | Взрывчатка 25 |
| Мины-«прыгуньи» Альянса | Внешние земли, аванпосты | Видны и слышны | Взрывчатка 40 или гравипушка |

| Электроловушки Пайщиков | Склады | БДИ 6 | Хакинг 25 / Ремонт 35 |
| Споровые «мешки» Садовников | КЗ | БДИ 6 | Выживание 40 / огонь |
