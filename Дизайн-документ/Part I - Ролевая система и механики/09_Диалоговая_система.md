# 09. Диалоговая система

> Уже есть (код мода): диалоги на KeyValues в `scripts/dialogs/*.txt`, узлы (`nodes`) с репликой NPC, хореографией и звуком, варианты ответа (`options`) с переходами, выдачей/завершением/провалом квестов, стадиями, требованием **одной** репутации и состояния квеста, «испорченными» NPC и повторными репликами.
> Нужно добавить: проверки характеристик и навыков, фракционные условия, эффекты (опыт, репутация, кредиты, предметы, флаги), варианты для низкой Аналитики и отношение NPC. Ниже — правила и предлагаемое расширение формата (**не код**, а спецификация для будущей реализации).

## 1. Принципы

1. **Герой молчит голосом, говорит текстом.** Как Гордон и как Курьер в NV: реплики игрока — текстовые варианты без озвучки. NPC озвучены (или субтитры для массовки).
2. **Первое лицо, без «киношных» камер.** Собеседник поворачивается к игроку (`auto_face_npc` уже есть). В HL нет кат-сцен, и у нас их тоже нет.
3. **Каждая важная беседа даёт минимум 3 тона:** вежливо/лояльно · нейтрально/по делу · дерзко/угрожающе. Плюс специальные (проверки).
4. **Проверки детерминированы и видны.** `[Красноречие 50]` зелёным — проходишь, красным — не проходишь, но выбрать можно (и получить провал).
5. **Провал — не стена.** Провал проверки ведёт в другую ветку: дороже, хуже отношение, бой, но квест продолжается.
6. **Мир помнит.** Отношение NPC, сделанные обещания, ложь, раскрытая позже.

## 2. Типы проверок

| Тип | Обозначение в тексте реплики | Пример |
|---|---|---|
| Навык | `[Красноречие 50]` | «[Красноречие 50] Вы же видите: у меня наряд на эту смену.» |
| Характеристика | `[Мощь 7]` | «[Мощь 7] (Сжать руку покрепче) Отдай.» |
| Ложь (особая проверка Красноречия) | `[Ложь 35]` | Провал лжи ГО → Подозрение +15 |
| Запугивание | `[Запугивание: Мощь 6 / Красноречие 40]` | Работает любой из порогов |
| Подкуп | `[Подкуп 50 кр.]` (цена с учётом Торговли и АВТ) | Только у продажных |
| Репутация | `[Лямбда: Признание]` | |
| Гражданский статус | `[ГС: Благонадёжный]` | |
| Перк | `[Двойной агент]` | |
| Предмет | `[Отдать: Банка тушёнки]` | |
| Человечность | `[Сострадание]` (Человечность ≥ 61) / `[Жестокость]` (≤ 39) | |
| Резонанс | `[Резонанс]` (≥ 35) — особые «знающие» реплики | «Здесь кто-то умер. Вчера. Я... вижу.» |
| Знание (флаг) | `[Знание: Сектор F]` | Открывается после сюжетных событий |
| Спутник | `[Виктор-6]` (если в отряде) | Спутник вмешивается |

**Пороговые значения:** 15 / 25 / 35 / 50 / 60 / 75 / 90 / 100 для навыков; 3–10 для характеристик.
**Опыт за успех** — порог ÷ 2 (навык) или 5 × значение (характеристика), внутри квеста — половина (файл 05).

## 3. Аналитика и «глупые» диалоги

### 3.1. Низкая Аналитика (АНА ≤ 3) — «Простак»
По примеру Fallout 1/2/NV: если АНА ≤ 3, многие ключевые узлы заменяются **упрощёнными** вариантами. Это не только шутка: у простака **свои плюсы**.

| Эффект | Описание |
|---|---|
| Реплики | Короткие, косноязычные, иногда трогательные: «Я... хорошо работать. Банку поднять. Где банка?» |
| ГО | Считают безобидным: **Подозрение растёт на 30% медленнее**, некоторые проверки ГО решаются фразой «Я не понимать» |
| Пайщики | Пытаются обсчитать (цены +15%), но иногда жалеют и подкармливают |
| Матушка Агата, вортигонты | Относятся с нежностью; Савва говорит с ним «проще» |
| Уникальные решения | Не менее 10 квестов имеют решение «только для простака» (например, пройти КПП, «заблудившись» вместе с рабочими) |
| Закрыто | Научные ветки, часть проверок Красноречия, сложные квесты Администрации |

Примеры:
```
Регистратор: «Цель прибытия?»
(обычно)  — «Не помню. Наверное, работа?»
(АНА ≤ 3) — «Поезд привёз. Я ехал. Теперь пришёл.»

ГО: «Подними банку.»
(обычно)  — «[Поднять банку и бросить в урну]» / «Сам подними.» / «[Красноречие 35] Офицер, урна вон там...»
(АНА ≤ 3) — «Банка! (поднимает, долго разглядывает, кладёт в карман) Моя теперь.»
          → ГО: «...Проходи, убогий.» (Подозрение −10)
```

### 3.2. Высокая Аналитика (АНА ≥ 8–9)
- «Научные» реплики `[Аналитика 8]` с точной терминологией и решениями «через ум».
- Ход разговора с учёными (Кляйнер, Квятковский, Рамбо) ощутимо глубже.
- Подсказки к прошлому героя: при АНА ≥ 9 он **слишком хорошо** понимает телепортационную технику, и NPC это замечают.

## 4. Отношение NPC (диспозиция)

У каждого именного NPC есть **отношение** −100…+100. Начальное значение = репутация его фракции × 0,5 ± личные модификаторы.

| Модификатор | Пример |
|---|---|
| Человечность героя | Агата +10 при «Сострадательном» |
| Черты и перки | «Образцовая анкета» — Лейла −10 |
| Подарки | Еда голодному +5…+15 |
| Обещания | Выполнено +10, нарушено −25 |
| Ложь, раскрытая позже | −20 и пометка «лжец» (недоступны некоторые проверки) |

| Отношение | Последствия |
|---|---|
| ≤ −50 | Отказ говорить / нападение (если позволяет фракция) |
| −49…−10 | Короткие ответы, цены +10%, проверки на 1 тир сложнее |
| −9…+29 | Обычно |
| +30…+69 | Доп. информация, скидки, небольшие подарки |
| +70 | Личные квесты, «ключевые» признания, помощь в финале |

## 5. Голос фракций в тексте (кратко; полный гайд — Part III/15)

| Кто | Манера |
|---|---|
| ГО | Сухо, командами, жаргон и коды: «Гражданин. Документы. Живо». Через вокодер — обрывки фраз |
| Надзор (солдаты) | Радиожаргон, позывные, механические подтверждения. Ординалы — без эмоций |
| Администрация | Канцелярит, эвфемизмы: «добровольное переселение», «оптимизация квартала» |
| Лямбда | По-человечески, с усталой иронией, учёные — с терминами |
| Косари | Рубленые лозунги, презрение к «шкурам» |
| Пайщики | Вежливость с угрозой, торговые метафоры: «У каждого своя доля» |
| Списанные | Просто, горько, с юмором висельников |
| Остаток (HECU) | Между собой — армейский английский (с субтитрами), с героем — общий язык; устав, мат (умеренно) |
| Вортигонты | Торжественно, о «нитях», «узах», «Вортэссенции»; к герою — «ты, кто нёс камень-сердце» |
| G-Man | Паузы, неожиданные ударения, вежливые угрозы. Никогда не отвечает прямо |

## 6. Структура важной беседы (шаблон)

```
[Приветствие — зависит от отношения/фракции/ГС/акта]
 ├─ Вопросы о мире (лор, слухи)              — без последствий
 ├─ Квестовая ветка                          — выдача, развилки, проверки
 │    ├─ Согласиться
 │    ├─ Торговаться [Торговля 35] / [Подкуп]
 │    ├─ Отказаться
 │    └─ Особые: [Аналитика 8], [Резонанс], [Знание: ...], [Спутник]
 ├─ Торговля / обучение / услуги
 ├─ Угрозы / нападение (если фракция позволяет)
 └─ Прощание (зависит от исхода)
```

## 7. Предлагаемое расширение формата KeyValues

Существующие ключи (`line`, `choreo`, `sound`, `options`, `text`, `next`, `close`, `grant_quest`, `complete_quest`, `fail_quest`, `set_stage`, `require_rep`, `require_quest_state`, `require_quest_stage`, `after_line`, `after_next`...) сохраняются. Добавляются:

### 7.1. Условия (доступность варианта)
| Ключ | Пример значения | Смысл |
|---|---|---|
| `require_attr` | `"ANA>=7"`, `"MIG<=3"` | Характеристика (LOV/ANA/MIG/BDI/DUH/AVT) |
| `require_skill` | `"speech>=50"` | Навык (ID из файла 03) |
| `require_faction` | `"lambda>=25"` | Репутация фракции (ID из файла 06) |
| `require_civil` | `"civil>=20"` или `"reliable"` | Гражданский статус |
| `require_item` | `"item_forged_id_card"` | Предмет в инвентаре |
| `require_perk` | `"PK-25"` | Перк |
| `require_flag` / `require_noflag` | `"mq02_done"` | Мировой или квестовый флаг |
| `require_humanity` | `">=61"` | Человечность |
| `require_resonance` | `">=35"` | Резонанс |
| `require_companion` | `"victor6"` | Спутник в отряде |
| `require_act` | `"1-2"` | Акт |
| `require_time` | `"night"` | Время суток (связь с `env_timecycle`) |
| `require_disposition` | `">=30"` | Личное отношение NPC к герою (раздел 4) |
| `require_suspicion` | `">=50"` | Текущее Подозрение (Part I/06, §3) |
| `hide_if_unmet` | `"1"` | Скрыть вариант, если условие не выполнено (по умолчанию — показать красным) |

### 7.2. Проверка с исходом
| Ключ | Пример | Смысл |
|---|---|---|
| `check` | `"speech:50"` или `"attr:MIG:7"` | Проверка, отображается в тексте как `[Красноречие 50]` |
| `next` | `"12"` | Узел при успехе |
| `fail_next` | `"13"` | Узел при провале |
| `check_once` | `"1"` | После провала повторить нельзя |

### 7.3. Эффекты (применяются при выборе варианта; у проверки — `on_success_*` / `on_fail_*`)
| Ключ | Пример |
|---|---|
| `xp` | `"25"` |
| `rep` | `"lambda:+10;reapers:-5"` |
| `civil` | `"-5"` |
| `suspicion` | `"+15"` |
| `humanity` / `resonance` / `influence` | `"+2"` / `"+5"` / `"+10"` |
| `credits` | `"-50"` |
| `give_item` / `take_item` | `"item_ration:2"` |
| `set_flag` / `clear_flag` | `"kadar_debt_paid"` |
| `disposition` | `"+10"` |
| `start_combat` | `"1"` |
| `open_barter` / `open_training` | `"1"` |
| `recruit` / `dismiss` | `"companion_victor6"` |

### 7.4. Узлы-варианты для низкой/высокой Аналитики
На уровне узла: `"line_low_ana"` (реплика NPC, если АНА ≤ 3) и вариант ответа с `"require_attr" "ANA<=3"`.

### 7.5. Пример (проверка на вокзале, Пролог)
```
"Dialog"
{
	"entity"        "npc_cp_trainstation_checkpoint"
	"auto_face_npc" "1"
	"nodes"
	{
		"1"
		{
			"line"          "Гражданин. Документы."
			"line_low_ana"  "Эй. Ты. Бумага есть?"
			"options"
			{
				"1" { "text" "[Протянуть временный пропуск]"  "next" "2"  "require_item" "item_temp_pass" }
				"2" { "text" "[Ложь 35] Мой пропуск у регистратора, офицер. Меня уже проверили."
				      "check" "speech:35"  "next" "3"  "fail_next" "4"
				      "on_success_xp" "9"  "on_fail_suspicion" "+15" }
				"3" { "text" "Я... хорошо. Банку поднять. Где банка?"  "require_attr" "ANA<=3"  "hide_if_unmet" "1"
				      "next" "5"  "suspicion" "-10" }
				"4" { "text" "Не твоё дело, железяка."  "next" "6"  "civil" "-3"  "suspicion" "+25" }
			}
		}
		"2" { "line" "Проходи. Не задерживай поток."  "end" "1" }
		"3" { "line" "...Проходи. И не попадайся мне больше."  "end" "1" }
		"4" { "line" "Ложь — это нарушение, гражданин. В сторону. Руки на стену."  "end" "1"  "server_sequence" "cp_search_player" }
		"5" { "line" "...Проходи, убогий."  "end" "1" }
		"6" { "line" "(Удар дубинкой) Ещё слово — и поедешь дальше. На Нова Проспект."  "end" "1" }
	}
}
```
