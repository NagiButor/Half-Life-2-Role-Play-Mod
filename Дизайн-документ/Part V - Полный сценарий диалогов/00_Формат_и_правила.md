## 2. Озвучка: сейчас текст, голос — в конце производства

Диалоги вводятся в игру **текстом** (субтитры и окно диалога). Музыка и озвучка добавляются последним этапом (Part VI/02). Поэтому у каждой сцены есть пометка озвучки.

| Пометка | Значение |
|---|---|
| **[Т]** | Только текст. Новая реплика, позже нужна запись. **По умолчанию для всех новых реплик**; в сценах ставится один раз в шапке |
| **[ВО: …]** | Можно взять **ванильную** реплику HL2 / Episode One / Episode Two (английский оригинал или официальный русский дубляж). В скобках — оригинальная фраза или группа реплик из кода игры (`METROPOLICE_*`, `COMBINE_*`, реплики горожан) |
| **[ВО?: …]** | Ванильная реплика подходит по смыслу, но не дословно. Решение — на этапе озвучки |
| **[Сборка]** | Реплика голоса Надзора, которую можно собрать из ванильных фрагментов (Part III/17) |

**Герой не озвучен.** Его реплики — текстовые варианты (Part I/09, принцип 1).

**Нельзя брать из ванили** (даже если реплика подходит): обращения «Гордон», «Фримен», «доктор Фримен», «Freeman», «Gordon», «doc» в адрес героя; реплики о событиях, которые в моде ещё не случились (восстание до Акта III, гибель Илая); фразы канонических персонажей, которые они в каноне говорят **другому** человеку в **другой** момент, если это ломает канон (R-01…R-10).

## 3. Шаблон сцены

```
## <ID> «Название квеста» — <номер сцены>. <название сцены>
> **Где:** сектор, объект · **Кто:** NPC · **Когда:** акт, время, условие запуска
> **Озвучка:** [Т] (исключения отмечены в репликах)
> **Флаги на входе:** ... · **Флаги на выходе:** ...

**Приветствие** (проверяется сверху вниз, срабатывает первое подходящее):
- `[условие]` **ИМЯ:** «реплика»
- `[иначе]` **ИМЯ:** «реплика»

### Узел 1 — <название>
**ИМЯ:** «реплика». *(ремарка)*
1. «Реплика героя». → 2
2. `[Красноречие 50]` «...» → ✔ 3 · XP 13 / ✖ 4 · Подозрение +10
3. `(АНА ≤ 3)` «...» → 5
4. `[Лямбда: Признание]` «...» → 6
5. `[Спутник: Виктор-6]` *(Виктор-6 вмешивается)* → 7
0. «Мне пора». → ■

### Узел 2 — ...

**Итоги сцены**
| Исход | Эффекты |
|---|---|
```

**Правила записи**
1. Реплики NPC — в кавычках-ёлочках после имени **КАПСОМ** или **Имени** жирным. Ремарки — курсивом в скобках.
2. Варианты героя нумеруются внутри узла: `1.`, `2.`… Вариант `0.` — всегда выход из разговора (если выход возможен).
3. Переход: `→ N` (узел), `↩` (назад в хаб NPC), `■` (конец разговора).
4. Проверка: `→ ✔ N · эффекты / ✖ M · эффекты`. Проверка видна игроку (зелёная или красная), кроме помеченных `(скрыто)`.
5. Эффекты — через `·` после перехода.
6. Если реплика NPC зависит от условий, варианты идут списком **внутри узла**, сверху вниз по приоритету.
7. Повторный разговор после квеста — отдельный блок **«Потом»** с вариантами по исходу.

## 4. Условия

| Запись в тексте | Смысл | Ключ KeyValues (Part I/09) |
|---|---|---|
| `[Красноречие 50]`, `[Взлом 25]`… | Навык ≥ порога, проверка с исходом | `check "speech:50"` |
| `[Мощь 7]`, `[Аналитика 8]`… | Характеристика ≥ порога | `check "attr:MIG:7"` |
| `(АНА ≤ 3)` | «Простак»; вариант виден только ему | `require_attr "ANA<=3"` + `hide_if_unmet` |

| `[Подкуп 50 кр.]` | Цена до скидок Торговли и АВТ | `credits` + `check` |
| `[Лямбда: Признание]` | Уровень репутации фракции (Враг, Неприязнь, Нейтралитет, Признание, Союзник) | `require_faction "lambda>=25"` |
| `[ГС: Благонадёжный]` | Гражданский статус не ниже (Антигражданин, Злостный нарушитель, Под наблюдением, Гражданин, Благонадёжный, Лоялист; в Прологе — «Временный пропуск») | `require_civil` |
| `[ГО: Офицер]`, `[ИК: 2-й разряд]`, `[Администрация: Писарь]` | Служебная линия | `require_flag` |
| `[Перк: Бумажная крепость]`, `[Черта: Тень костюма]` | Перк или черта | `require_perk` |
| `[Предмет: Поддельная карта]`, `[Отдать: Паёк ×1]` | Наличие или передача предмета | `require_item` / `take_item` |
| `[Сострадание]` / `[Праведность]` | Человечность ≥ 61 / ≥ 81 | `require_humanity` |
| `[Жестокость]` / `[Пустота]` | Человечность ≤ 39 / ≤ 19 | `require_humanity` |
| `[Резонанс ≥ 35]` | Резонанс не ниже; «знающие» реплики | `require_resonance` |
| `[Знание: Сектор F]` | Флаг знания из сюжета | `require_flag` |
| `[Спутник: Савва]` | Спутник в отряде | `require_companion` |
| `[Акт II]`, `[Ночь]` | Акт, время суток | `require_act`, `require_time` |

## 6. Правила содержания

1. **Минимум три тона** в каждом важном узле: лояльно/вежливо · по делу · дерзко/угрожающе (Part I/09). Плюс специальные варианты.
2. **Провал проверки — не тупик.** Квест продолжается иначе: дороже, хуже, через бой.
3. **«Простак» (АНА ≤ 3)** получает свой вариант в каждой ключевой сцене. Он искренний, а не глупый ради смеха (Part III/15, п. 8). Примерно в десяти квестах у простака есть уникальное решение.
4. **Человечность** меняет и слова героя, и реакцию NPC: у `[Сострадание]` — бескорыстные варианты, у `[Жестокость]` — циничные. Вортигонты, Матушка Агата, отец Григорий реагируют на Человечность сильнее других.
5. **Резонанс** даёт «знающие» реплики: герой видит прошлое места или чувствует G-Man. Не злоупотреблять: не больше одной такой реплики на сцену.
6. **Спутники вмешиваются** в 1–2 узлах каждого квеста, где им есть что сказать (Part I/13: одобрение и неодобрение).
7. **Мир помнит.** У квестодателя есть блок «Потом»: реплики по исходу квеста и по флагам мира.
8. **Канон.** R-01…R-10 (Part 0/07). Гордон — только издали и в эфире. Канонические персонажи говорят своим голосом (Part III/15, §4). G-Man — редко, с паузами, ничего не объясняет.
9. **Имена.** Только из Part III/06 и Part 0/09. Новые второстепенные NPC — по пулам Part 0/09, с указанием происхождения; их список — в конце файла.
10. **Голос Надзора и эфир ГО** — по Part III/17: обращения, код-триады, коды ГО, позывные.

## 8. Пример: КПП Гражданской обороны на вокзале (системная сцена)

> **Где:** C17-01, вокзал, выход в город · **Кто:** юнит ГО «Экс-рей-4» (генерик в маске) · **Когда:** Пролог — Акт III, при каждом проходе через КПП, если Подозрение ≥ 25 или ГС ниже «Гражданина»; в Прологе — всегда
> **Озвучка:** [Т]; реплики ГО частично [ВО], отмечены
> **Флаги на входе:** `mq00_registered`, `item_temp_pass` · **Флаги на выходе:** `checkpoint_trainstation_passed`

**Приветствие**
- `[Флаг: player_is_cp_disguised]` `[маскировка не раскрыта]` **ГО:** «Юнит. Смена?» → узел 6
- `[ГС: Лоялист]` **ГО:** «Проходите, гражданин. Хорошего цикла». ■ *(без проверки)*
