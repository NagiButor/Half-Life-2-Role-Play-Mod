# 12. Жизнь мира: распорядок, патрули, типовые NPC, случайные встречи

> Fallout живёт не только уникальными персонажами, но и «генериками»: караванами, патрулями, бродягами, с которыми **можно поговорить и поторговать**. Здесь — правила этой массовки.

---

## 1. Типовые NPC (с ними можно говорить)

Каждый «генерик» имеет **набор реплик** по ситуации (приветствие, слухи по акту, реакция на ГС/Подозрение/репутацию героя, торговля, если есть) и **флаг роли** (доносчик, продажный, торговец, может дать поручение).

| Тип | Где | Что умеет | Пример реплики (Акт I) |
|---|---|---|---|
| Гражданин | Город | Слухи, жалобы; 1 из 5 — доносчик; иногда даёт мелкое поручение (T1) | «Опять паёк с привкусом... чего это они туда кладут?» |
| Рабочий Альянса | Стройки, промзона | Слухи о работе, наряды; торг инструментами | «Говорят, страйдер в доке опять "чихает". Мне платят не за то, чтобы я знал, что это значит.» |
| Хазмат ИК | КЗ, KZ-01 | Слухи о КЗ, продаёт противогазы | «Если пена шевелится — не трогай. Просто уходи.» |
| ГО (юнит) | Город | Проверки, приказы, взятки (если продажный), слухи «для своих» на пути ГО | «Гражданин. Пройдите. Не создавайте поток.» |
| Солдат Надзора | Аванпосты, город с Акта III | Не разговаривает (кроме пути ГО/маскировки: радиообмен) | «...Сектор чист. Ожидаю.» |
| Беглец | Каналы, Пустошь | Просит еды, указывает тайники | «Ты оттуда? Скажи... мой брат ещё в Семёрке? Петров, кв. 6?» |
| Повстанец | Убежища, Пустошь | Слухи, мелкие поручения, торговля патронами | «Видел λ на опоре? Значит, рядом вода и свои.» |
| Списанный | Пустошь | Бартер, просьбы, проводит по тропам | «Нас не убили. Нас просто перестали кормить.» |
| Караванщик / Коробейник | Пустошь, Побережье, Внешние земли | Торговля, слухи по всему региону | «Смола? Беру. Кредиты? Беру, но по курсу.» |
| Ветеран Остатка | Внешние земли | Армейские слухи, торговля, английский | «Stay frosty. Тут вам не город.» |
| Бандит Вольницы | Внешние земли | Требует «пошлину», можно договориться | «Свобода, брат, не бесплатная. Плати.» |
| Вортигонт (Хор) | Пустошь | Загадочные речи, лечение | «Ты идёшь, и нить тянется за тобой. Длинная нить.» |

## 2. Распорядок NPC (связь с `env_timecycle`)

| Время | Граждане | ГО | Рабочие | Подполье | Пустошь |
|---|---|---|---|---|---|
| 06:00–07:00 | Встают, очереди к раздатчикам | Смена постов | К проходным | Спят | Рассвет: охотники выходят |
| 07:00–19:00 | Работа, очереди, рынок | Патрули, проверки | Смены | Явки закрыты | Караваны, работа в огородах |
| 19:00–комендантский час | Двор, рынок, бани | Усиление | Домой | Встречи «по делу» | Костры, рассказы |
| Комендантский час | Дома | Двойные патрули, сканеры с прожекторами | — | **Активность**: контрабанда, собрания, рейды | Ночь опасна: зомби, муравьиные львы |

NPC «вне расписания» (на улице в комендантский час) — **всегда история**: беглец, контрабандист, влюблённые, пьяный, Безликий (SQ-09).

## 3. Патрули

| Патруль | Состав (Акт I → IV) | Маршрут | Поведение |
|---|---|---|---|
| ГО «группа защиты» | 2 юнита → 3 юнита + мэнхэк → Надзор (Акт III) | Кварталы, площади | Проверки документов при Подозрении ≥ 25; «Подберите банку» |
| Сканеры | 1–2 → 3–4 на сектор | Над улицами | Фото нарушений; в Акте II ночью — с прожекторами |
| Бригада ИК | 3 хазмата + грант (+ чарджер в Акте II) | КЗ | Пена, образцы; на героя-нелегала — арест или огонь |
| Надзор (за стеной) | 3–4 гранта + ординал | Дороги, аванпосты | Огонь по любому без наряда |
| Вольница | 3–5 бандитов | Дороги Внешних земель | «Пошлина»; при отказе — бой или проверка Красноречия/Мощи |
| Стервятники | 2–6 | Пустошь | Засады, всегда враги |
| Остаток (разведка) | 2–3 ветерана | Внешние земли | Нейтральны, если репутация ≥ 0; могут нанять/предупредить |
| Хор | 1–2 вортигонта | Пустошь | Помогают раненым; убегают от Альянса |
| Караван Списанных | 3 человека + навьюченный «тачкой» груз | Пустошь ↔ Заречье ↔ «Сосны» | Торговля; в Акте II+ просят сопровождения |

## 4. Случайные встречи

Срабатывают при **переходе между точками за стеной** (быстрое перемещение и пешие маршруты) и при **ожидании** в городе. Вес встречи зависит от акта, региона и времени суток.

### Город
| Встреча | Акты | Суть |
|---|---|---|
| «Подберите банку» | I–II | Юнит требует унизительного подчинения (PK-02) |
| Обыск на улице | I–III | Досмотр: проверка контрабанды |
| Драка за паёк | II–III | Вмешаться / пройти мимо / ограбить победителя |
| Беглец просит спрятать | I–III | Укрыть (+Человечность, риск) / сдать (+ГС) |
| Листовщик Лямбды | II–III | Помочь раздать (−ГС тайно, +Лямбда) / сдать |
| Продажный ГО «трясёт» гражданина | I–II | Заступиться, подкупить, наблюдать |
| Явление G-Man | I–IV | Редкое: фигура в конце улицы, в окне трамвая |
| Снаряд с хедкрабами | III–IV | Капсула падает на улицу [К] |
| Мародёры в брошенной квартире | IV | Бой / договор |

### Пустошь и Побережье
| Встреча | Суть |
|---|---|
| Беглецы в тупике | Проводить до Пристани / ограбить / сдать патрулю |
| Засада Стервятников | Бой; иногда — их пленники |
| Караван Списанных под атакой | Помочь — репутация + товар |
| Одинокий вортигонт у костра | «Суп», слухи, иногда квест Хора |
| Хедкрабья «полянка» | Гнездо, лут на трупе |
| Вертолёт-охотник (Акт II+) | Укрыться / сбить (РПГ) |
| Муравьиные львы на песке | Камни, тампер, приманка |
| Рыбак-отшельник | Обмен рыбы, байки |
| Пасхалка: гном Чомски на пне | Только с чертой «Дикий Ксен» → SQ-60 |

### Внешние земли
| Встреча | Суть |
|---|---|
| «Пошлина» Вольницы | Платить / драться / `[Красноречие 50]` / `[Мощь 8]` |
| Патруль Остатка | Знакомство, армейские слухи, торговля |
| Буллсквид у ручья [D] | Бой, редкое мясо |
| Брошенная машина с припасами | Лут (иногда — ловушка) |
| Коробейник Митрич | Торговля |
| Охотник (синт), Акт IV и пост-игра | Тяжёлый бой |
| Страйдер на хребте | Прятаться (скайбокс → реальность) |
| Беженцы из Сити-17 (Акт IV) | Поток людей с узлами — проводить до Белого Леса / «Сосен» |

## 5. «Мир помнит» — мелкие реакции массовки

| Поступок героя | Реакция «генериков» |
|---|---|
| ГС «Лоялист» | Граждане притихают при нём; один плюнет вслед |
| ГС «Антигражданин» | Граждане разбегаются; кто-то тайком суёт еду |
| Помог Списанным | В Пустоши здороваются, дарят овощи |
| Сдал соседа | В Квартале 7 шёпот за спиной, цена у соседей +20% |
| Герой-ГО в маске | Граждане отводят глаза, дети... детей нет |
| Высокая Человечность | Беглецы сами приходят просить помощи |
| Низкая Человечность | Разговоры обрываются при приближении |
| Резонанс ≥ 60 | Вортигонты кланяются; собаки (если есть) воют; сканеры «зависают» рядом |
