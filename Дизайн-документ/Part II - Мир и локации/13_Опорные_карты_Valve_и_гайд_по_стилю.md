## 2. Правила стиля Valve, которые мы соблюдаем

### Композиция и навигация
1. **Ориентир всегда виден.** Цитадель — главный компас города. За городом ориентиры — горы, плотина, маяк, мыс Нова Проспекта.
2. **Свет ведёт игрока.** Тёплое пятно света у нужного прохода, холодный — у опасности.
3. **Точка «вау» на сектор.** Каждый сектор имеет одну открывающуюся панораму: страйдер за домами, Цитадель в проспекте, плотина из-за поворота.
4. **Вертикаль.** Крыши, балконы, трубы, подвалы — минимум два уровня маршрутов.
5. **Обучение без текста.** Новая механика сначала показывается безопасно (как первый барнакл в каналах).

### Детализация
6. **Плотность у пола:** мусор, бумаги, банки, пайки, гильзы, детали быта. Пустые стены — грех.
7. **Человеческое под инородным:** облупленный советский модерн и вбитые в него стальные «жала», кабели и панели Альянса.
8. **Истории в окружении:** квартира со списанной семьёй (вещи брошены на полпути), кукла в пустом детском саду КЗ, рисунки в пионерлагере, записка в танке.
9. **Граффити λ** как навигационный язык «своих». Плюс наш новый язык граффити: **«Косари»** (серп), **«Пайщики»** (монета с прорезью), **«Списанные»** (перечёркнутый штрихкод).

### Звук
10. Голос Надзора в громкоговорителях задаёт «пульс» района.
11. Далёкий шаг страйдера, вертолёт, сирена — фон даже в тихих местах.
12. Тишина КЗ и Ксена — инструмент страха.

### Техника (под Source)
13. Интерьеры — через `areaportal`, улицы — через `occluder` и `hint`.
14. Дальние дома — модели с LOD и fade. Совсем дальние — в 3D-скайбоксе.
15. Население — спавн-зоны рядом с игроком; не держать > ~120 NPC в секторе (лимит 2048 сущностей).
16. Слои актов — группы объектов, включаемые логикой при загрузке, а не копии карт.

## 3. Шаблон «паспорта сектора» для левел-дизайнера

```
ID / имя:             C17-xx — ...
Размер (юниты):       ширина × длина × высота; класс (малый/средний/...)
Связи:                [ID] — тип перехода — место перехода — условия
Играбельно (🟩):      список зон
Видно, недоступно (🟨): список
Скайбокс (🟦):        набор и ориентиры
Слои:                 act1 / act2 / act3 / act4 / post / flag_*
Население:            уникальные NPC (с расписанием), генерики, патрули
Квесты:               ID + точки на карте
Замки и тайники:      объект — требование — награда
Звук и свет:          амбиент по актам, ключевые источники света
Бюджет:               NPC ≤ __, физобъектов ≤ __, отражений/кубмапов __
Референсы Valve:      карты, скриншоты
```
