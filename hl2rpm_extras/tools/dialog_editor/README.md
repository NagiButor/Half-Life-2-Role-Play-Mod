# HL2RPM Dialog Editor

Визуальный редактор диалогов NPC, квестов и озвучки мода HL2RPM.
Запуск: `E:\SourceModding\HL2RPMSOURCE\HL2RPM Dialog Editor\HL2RPM Dialog Editor.exe`
(сборка — `build_editor.ps1`, исходники — эта папка).

## Проект

Проект (`*.hl2dlg`, JSON) хранит всех NPC, их реплики на всех языках, квесты,
привязанную озвучку и положение карточек на холсте. **Ctrl+S** сохраняет проект
и раскладывает всё по папкам игры («Папка игры» в настройках проекта):

| Что | Куда |
|---|---|
| диалог NPC + его квесты, все языки | `scripts/dialogs/<targetname>.txt` |
| озвучка (WAV/MP3/OGG/FLAC → WAV 16 бит моно для Source) | `sound/dialogs/<targetname>/<язык>/<номер>.wav` |
| сцена с липсинком (генератор мода) | `scenes/dialogs/<targetname>/<язык>/<номер>.vcd` |

Липсинк создаётся только для изменённых реплик (новый текст или новый звук).
Файлы, которые редактор записал сам, он сам и убирает (переименовали NPC,
сменили номер реплики — файлы переезжают). Чужой файл диалога перед первой
перезаписью копируется в `*.txt.bak_<дата>`.

## Холст

- колесо — масштаб к курсору; средняя/правая кнопка или Пробел+ЛКМ — двигать; **F** — вписать всё
- двойной клик по пустому месту / **N** — новая реплика; **Delete**, **Ctrl+D**, **Ctrl+L** (авто-раскладка)
- кружок справа у ответа → тянуть к реплике = связать; в пустое место = создать реплику
- WAV/MP3 перетащить на реплику — озвучка на языке из списка «Язык» сверху;
  несколько файлов на холст или «Озвучка из папки…» — привязка по именам `0.wav`, `105.wav`, `returning.wav`, `<номер>_<вариант>_after.wav`
- плашки языков в шапке реплики: зелёная — озвучка + липсинк, жёлтая — липсинк создастся при сохранении,
  серая — нет озвучки, красная — файла нет; красные буквы — нет перевода
- бейджи ответов: `+квест` выдаёт, `✓` завершает, `✗` проваливает, `этап`, `если` (условия), `✕` закрывает диалог

**F5** — пройти диалог прямо в редакторе (озвучка, квесты, репутация, повторный визит),
**F6** — сохранить и запустить карту с NPC, **F8** — обновить диалоги в запущенной игре (`-hijack +dialog_reload`),
**F7** — проверка проекта (ссылки, переводы, озвучка, байты, NPC на картах).

## Языки в игре

Один файл диалога несёт все языки: `"line"` — основной язык проекта,
`"line_russian"` — перевод; так же `text`, `after_line`, `returning_line`,
`display_name`, `title`/`desc` квестов, и озвучка `choreo_<язык>` / `sound_<язык>`.
Игра берёт язык из `dialog_language` (пусто = язык игры: `cl_language` / Steam).
Проверка: `dialog_language english` / `russian` в консоли — диалоги перечитываются сразу.

## Сборка

```
powershell -File build_editor.ps1
```
Создаёт venv (PySide6, numpy, PyInstaller) в `E:\SourceModding\HL2RPMSOURCE\dialog_editor_build`
и кладёт программу в `E:\SourceModding\HL2RPMSOURCE\HL2RPM Dialog Editor`.
Без сборки: `python hl2rpm_dialog_editor.py [проект.hl2dlg]` (нужны PySide6 и numpy).

Липсинк — копии генераторов мода (`dlgedit/lipsync_gen/vcd_english.py`, `vcd_russian.py`,
из `testmaps/scenes/demo_npc_1*/generate_vcd*.py`); новый язык — свой `vcd_<язык>.py`
и строка в `lipsync._GENERATORS` (без него — английские правила).
