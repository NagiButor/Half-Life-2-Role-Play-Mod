# HL2RPM Creation Kit

Редактор контента мода HL2RPM «по типу GECK»: карты в 3D с NPC, маркерами (кровати,
стулья, столы, стены), предметами, контейнерами и маршрутами; NPC с распорядком дня
(пакеты ИИ), фракции; диалоги, квесты и озвучка.
Запуск: `E:\SourceModding\HL2RPMSOURCE\HL2RPM Creation Kit\HL2RPM Creation Kit.exe`
(сборка — `build_editor.ps1`, исходники — эта папка, точка входа `hl2rpm_creation_kit.py`).

## Проект

Проект (`*.hl2dlg`, JSON) хранит всех NPC (реплики на всех языках, «персонажа» и
распорядок), квесты, фракции, всё, что поставлено на каждую карту, и узлы навигации.
**Ctrl+S** сохраняет проект и раскладывает файлы по папкам игры («Папка игры» в настройках):

| Что | Куда |
|---|---|
| диалог NPC + его квесты, все языки (только у NPC с репликами) | `scripts/dialogs/<targetname>.txt` |
| озвучка (WAV/MP3/OGG/FLAC → WAV 16 бит моно для Source) | `sound/dialogs/<targetname>/<язык>/<номер>.wav` |
| сцена с липсинком (генератор мода) | `scenes/dialogs/<targetname>/<язык>/<номер>.vcd` |
| персонаж: класс, модель, оружие, фракция, флаги, лут, распорядок | `scripts/npcs/<targetname>.txt` |
| что поставлено на карту | `scripts/world/<карта>.txt` |
| узлы навигации карты | `scripts/world/<карта>_nav.txt` |
| фракции и отношения | `scripts/world/factions.txt` |

Файлы, которые программа записала сама (заголовок `HL2RPM Creation Kit: generated`), она сама
и убирает; чужой файл перед первой перезаписью копируется в `*.bak_<дата>`.
Файл → «Импорт мира из игры» загружает `scripts/npcs` и `scripts/world` в проект.

## Карта (окно в 3D)

Сверху выбирается карта (`.bsp` из `hl2rpm\maps` и `testmaps\maps`; после компиляции в Hammer — ⟳).
Видно всё как в игре: мир, дисплейсменты, статические пропы, NPC из Hammer; плюс объекты проекта.

- **правая кнопка + WASD** — полёт (Q/E — вниз/вверх, Shift — быстрее, колесо при зажатой правой — скорость),
  колесо — вперёд/назад, средняя кнопка — сдвиг, **F** — к выделенному; **Z** — полёт без кнопки (как в Hammer++)
- **гизмо** у выделенного: стрелки и плоскости — двигать, короткий щелчок правой по выделенному — круги поворота;
  **End** — «Приземлить» (касание пола самой низкой точкой; «по наклону поверхности» — по нормали);
  рамка по пустому месту — выделить несколько, Ctrl+C / Ctrl+V — копировать (и на другую карту)
- **пропы и сущности самой карты** (из VMF в `mapsrc`) выделяются и правятся так же; новые — с палитры
  «В саму карту» или перетаскиванием с вкладки «Модели»; Ctrl+S пишет VMF (с копией `.bak_<время>`),
  **⚙ Собрать карту** (F9) — компиляция `hl2rpm_vbsp/vvis/vrad` в фоне (только сущности — за секунды)
- **левая кнопка** — выделить; тащить — двигать по поверхностям (Ctrl — по сетке 16), **Alt+тащить** — повернуть
  лицом к курсору, **[ ]** — поворот на 15°, **Delete** — удалить, **Ctrl+D** — копия
- слева «**Объекты**»: двойной клик → клик на карте — поставить NPC проекта, маркер, предмет, контейнер,
  проп, маршрут патруля (клики — точки, Enter или правая кнопка — готово), свою сущность; Shift+клик — несколько
- правая кнопка на карте — «Поставить сюда», «Опустить на пол», «Игра отсюда», «Вид сверху сюда»
- слева «**На карте**» — всё поставленное и NPC из Hammer; клик — выделить, двойной — показать
- ползунок **«Время»** — где кто в этот час: подпись над NPC и линии к месту текущего пакета
- **Навигация ▾** → «Сгенерировать в игре»: игра загружает карту, раскладывает узлы (`rpm_nav_generate`),
  программа забирает их в проект; «Править узлы» — клик добавляет, тащить — двигать, Delete — удалить
- **▶ Игра отсюда** (F6 с окна карты) — сохранить и запустить карту, игрок появится на месте камеры, время — с ползунка

## NPC: Диалог / Персонаж / Распорядок

- **Персонаж** — класс (горожанин, ГО, солдат, вортигонт, зомби…), модель (… — выбрать любую из игры), скин,
  оружие, здоровье, фракция, отношение к игроку, отряд; «враг, если ранить», «молчит, если ранить»,
  «бессмертный», «можно позвать в отряд игрока»; лут трупа; где стоит на картах; дополнительные ключи.
- **Распорядок** — пакеты ИИ. В каждый момент работает **первый** пакет списка, у которого подходит время
  и условие квеста (как в GECK). Суточная шкала сверху показывает, что NPC делает в каждый час.
  Пакеты: Сон, Еда, Свободное время, Патруль, Бродить, Идти и остаться, Охрана, Маркер, Стоять,
  Следовать, Заговорить (подходит к игроку и открывает свой диалог). Бой, скрипты карты и разговор с игроком
  прерывают распорядок. Распорядок есть у горожан, Аликс, Барни, вортигонтов, ГО, солдат, зомби.
- **Маркеры** (кровать, стул/диван, стол, стена, земля, работа, пост, точка ожидания) — место и анимация
  (из `actbusy.txt` игры); владелец — только этот NPC («своя кровать»). Ставьте маркер туда, где должен
  оказаться NPC, стрелка — куда он смотрит. Отметка «✓ у модели есть эта анимация» — проверка по модели NPC.
- **Фракции** — слева «Фракции»: отношение к игроку и к другим фракциям (= ftag NPC).
- **Бой** — меткость, опыт за убийство. **Торговец** — товары (список лута `list:<id>` и/или предметы), деньги,
  по какой цене продаёт и покупает, через сколько часов новый товар, валюта; окно торговли открывает вариант
  ответа с флажком «Открыть торговлю» в его диалоге.
- **Шаблон и вариации** — шаблон (другой NPC проекта): пустые поля берутся из него; «Это шаблон» — основа для
  других NPC и точек появления. Модели/оружие/имена (мужские и женские отдельно), скин — случайно для каждого
  появившегося NPC: один шаблон «Горожанин» даёт толпу разных людей.

## Предметы, лут, замки, торговля, переходы

- Вкладка «**Предметы**»: свои предметы (записки и книги с текстом, ключи, деньги, еда, медицина, оружие…) и
  стоковые HL2 («+ стоковые»): название и описание на языках, вес, цена, категория, модель; файлы игры —
  `scripts/rpg/items.txt`. **Списки лута**: «предмет, кол-во от–до, шанс, мин. уровень, вложенный список»;
  в лут контейнера, трупа, торговца пишется `list:<id>` — список разворачивается при первом открытии.
- **Контейнер** на карте: замок (ключ-предмет и/или уровень взлома), пополнение через N игровых часов.
  Двери Hammer (`prop_door_rotating`) — ключи `rpm_key`, `rpm_lock_level` (в FGD).
- **Точка появления** (палитра «Прочее»): кого создаёт (NPC проекта, лучше шаблоны, или классы игры, с весами),
  сколько живых, радиус, с какого расстояния включается, часы, пополнение, флаг мира. NPC появляются вне поля
  зрения игрока.
- **Переход на другую карту** (палитра «Прочее»): коробка — игрок входит, грузится другая карта, он появляется
  перед парным переходом там (по стрелке). «Карта» → «Создать парный там» → «Открыть ту карту» — передвинуть
  парный. Поворот перехода — куда смотрит пришедший. Инвентарь, квесты, время и погода переносятся;
  пересобирать карты не нужно.

## Задания, логика, проверки навыков, автоперевод

- **Условия и действия** — одни и те же везде: варианты ответа и реплики, этапы и цели заданий, события,
  условие присутствия объектов карты, пакеты распорядка. Список читается фразами («задание «Поставка» активно,
  этап ≥ 1 И флаг door_open»); «+ условие» / «+ действие», двойной клик — изменить. Условия: задание (состояние,
  этап, цель), флаг, переменная, предмет у игрока, навык, характеристика, уровень, репутация, время суток, день,
  погода, карта, игрок в зоне / рядом с, NPC жив / враждебен, уже говорил, здоровье, костюм, событие было, шанс;
  «НЕ» и «ИЛИ со следующим». Действия: дать / забрать предмет, жетоны, опыт, флаг, переменная, задание
  (выдать, этап, отметить цель, выполнить, провалить), репутация, **NPC / фракция нападает**, сообщение на экран,
  звук, перенести игрока, начать диалог, торговля, убить, убрать объект, затемнение, время, погода, навык,
  ввод сущности Hammer, консольная команда; у каждого — задержка. В диалоге действия «⏏» (нападение, перенос,
  торговля, другой диалог) срабатывают после закрытия окна.
- **Вариант ответа**: «Условия» (+ «показывать серым», как в New Vegas), «Проверка навыка» — «[Красноречие 50]»
  перед текстом: хватает — «Следующая реплика» и действия, не хватает — реплика провала и действия провала;
  «одна попытка» — потом вариант скрыт. Кнопки «NPC нападает», «Вся фракция нападает», «+ опыт».
- **Вкладка «Задания»** (файл игры — `scripts/rpg/quests.txt`, общий для всех NPC): этапы с целями — убить,
  собрать предмет, поговорить, дойти до (зона / NPC / объект), использовать (E), по условиям, вручную (действием
  «отметить цель»). Все обязательные цели выполнены — этап переходит дальше сам (или «задание выполнено»).
  У этапа — действия при начале; у задания — опыт, «при выполнении», «при провале», «провалить, если».
  Цели видны в журнале игры (`rpm_journal` — назначьте клавишу: `bind j rpm_journal`), на экране — маркер с
  расстоянием над целью.
- **Вкладка «Логика»**: события «когда … и условия → действия» — игрок пришёл на карту, вошёл / вышел из зоны,
  убит NPC, использовал объект, заговорил с, наступил час, задание выдано / этап / выполнено / провалено,
  «когда условия станут верны»; «один раз», задержка, только на карте. «Флаги и переменные» — список с
  описаниями и значениями новой игры (`scripts/rpg/events.txt`, `globals.txt`).
- **Зона** (палитра «Прочее»): невидимая коробка с именем для событий, целей «дойти до», условия «игрок в зоне».
- **Условие присутствия** у объекта карты: объект есть в игре, пока условия верны (баррикада после задания,
  NPC переехал); NPC не исчезает на глазах, убитый / взятый не возвращается.
- **Проект → Автоперевод (Google)**: заполняет пустые переводы всего проекта или диалога NPC (интернет, без
  ключа); машинный перевод помечен «МП», пока его не поправят руками; ручные переводы не трогаются.
- **Игра → Состояние для запуска**: задания на этапе, флаги, переменные, навыки, предметы, уровень, время,
  погода — F6 и «Игра отсюда» стартуют с ними (`scripts/rpg/test_state.txt`, `+rpm_test_state`).
- **F5** (проверка диалога) считает условия, проверки и действия; навыки, флаги, переменные, предметы и время
  задаются слева.

В игре: `rpm_logic_debug 1` (2 — и каждое условие), `rpm_events_dump`, `quest_dump`, `rpm_state_dump`,
`rpm_skill speech 60`, `rpm_flag`, `rpm_var`, `quest_grant <id>`.

**F5** — пройти диалог прямо в программе, **F6** — запустить в игре, **F8** — обновить диалоги и мир в
запущенной игре (`-hijack +dialog_reload +rpm_world_reload 1`: объекты слоя создаются заново),
**F7** — проверка проекта (ссылки диалогов, пакеты без маршрута/маркера, повторы имён, переводы, озвучка).

В игре: `rpm_ai_debug 1` — над NPC пакет и что он делает, `rpm_world_dump` — список, `sv_timecycle_set_time 23` — время.

## РПГ: персонаж, перки, черты, новая игра

- **Вкладка «РПГ»**: «Правила» — все числа персонажа (очки при создании, отмеченные навыки, формула навыка, очки за
  уровень, перк каждые N уровней, здоровье, вес, урон по навыку, криты, опыт за врага / взлом / проверку, репутация) с
  живым примером «при всех характеристиках 5…»; «Характеристики и навыки» — названия и описания на языках, от какой
  характеристики растёт навык; «Перки» и «Черты» — в пустом проекте кнопка «Добавить стандартные перки и черты»
  (20 + 8 в духе New Vegas); у перка — с какого уровня, ранги, требования (характеристика / навык ≥ N), эффекты.
- **«Новая игра»**: карта, точка появления («Указать на карте…»), окно создания персонажа, имя по умолчанию, время,
  погода, жетоны, снаряжение, первое задание, ещё действия; «Записать cfg/chapter1.cfg» — чтобы «Новая игра» в меню
  запускала эту карту.
- **Логика**: условия «У игрока перк», «Персонаж создан», «Репутация» с фракцией; действия «Дать перк», «Окно
  создания персонажа» (как у доктора в New Vegas), «Репутация ±» с фракцией (−50 и ниже — фракция нападает).

В игре: `rpm_character` — лист персонажа (назначьте клавишу: `bind c rpm_character`), повышение уровня открывается
само вне боя; `rpm_char_dump`, `rpm_xp 300`, `rpm_perk <id>`, `rpm_rep <фракция> <±N>`, `rpm_char_create`.

## Звук: музыка, звуковые сцены, фразы NPC

- **Вкладка «Звук»**: треки музыки по типам — исследование (днём / ночью), бой, тема локации, короткая вставка
  (стингер: сама на «открыта локация», «задание выдано / выполнено / провалено» или действием); громкость, только на
  картах. «Импорт музыки…» кладёт свои MP3/WAV/OGG/FLAC в `sound/music/hl2rpm/` папки игры (не MP3 — через ffmpeg),
  «…» у файла — выбор из звуков игры (и из VPK) с фильтром и прослушиванием, ▶ — послушать. Пустой проект —
  кнопка «Добавить треки HL2». Звуковые сцены — петли и группы случайных звуков (раз в N–M с, громкость, тон).
  Наборы фраз — общие для классов NPC (горожане, ГО) или для выбранных NPC.
- **NPC → «Фразы»**: стоковые фразы HL2 (все / только боевые / нет; о Фримене — никогда), общие наборы, свои фразы:
  когда (подошёл игрок, просто так, прощание, ранен, бой, с оружием, убит союзник, убил, начался пакет, по действию),
  текст на языках, озвучка с липсинком (как реплика) или звук игры, вес, пауза, шанс, «один раз», условия.
- **Зона → «Локация»**: название (при первом входе — «Новая локация», опыт, вставка), музыка, звуковая сцена.
- **Палитра → Прочее → «Звук на карте»**: звук в точке (гул, капли, радио), слышно на N ед. или везде;
  время суток и задания — условием присутствия.
- **Действия**: «Сменить музыку» (пусто — вернуть обычную), «Музыкальная вставка», «Фраза NPC».

В игре: `rpm_audio_debug 1`, `rpm_music_dump`, `rpm_music_status`, `rpm_bark <npc> idle`, громкость — «Музыка» в
настройках звука (`snd_rpm_music` поверх).

## Просмотр моделей и анимаций, превью света

- **Просмотр модели и анимаций**: ПКМ по NPC, пропу или маркеру на карте → «Просмотр модели и анимаций…» («Анимация маркера…»),
  у NPC — кнопка «Анимации…» под моделью. Все анимации модели и подключённых к ней (у горожан — male_shared, сцены, жесты, позы):
  поиск по имени или ACT_…, проигрывание, кадр, скорость, кости, скин. ЛКМ — вращать, ПКМ — двигать, колесо — ближе / дальше.
- **Показать → «Манекены на маркерах»** (включено по умолчанию, как в GECK): на каждом маркере стоит фигура и играет его
  анимацию — лежит на кровати, сидит за столом, прислонилась к стене. Так видно, как это будет в игре, и куда подвинуть
  или повернуть маркер (анимация дивана сажает тело на 24 ед. позади маркера — маркер ставится перед диваном, а не в его
  центр; лёжа тело вытянуто вдоль стрелки «влево» маркера). Модель — владельца маркера, иначе горожанин. Тот же маркер в игре — место,
  куда может сесть и игрок: «[E] Сесть / Лечь / Прислониться», камера от третьего лица, встать — E, прыжок или шаг.
- **Показать → «Анимации NPC (распорядок часа)»**: NPC проекта на карте делают то, что делают в выбранный ползунком час —
  на маркере пакета играют его анимацию (спят на кровати, сидят за столом), остальные стоят.
- **Показать → «Освещение: лампы и солнце часа»**: превью света — лампы карты (light_deferred, прожекторы, классические light /
  light_spot; новые — палитра «В карту» → «Лампа» / «Прожектор»), у 4 ближайших — тени от мира, солнце и небо по ползунку
  времени. «Ночь (только лампы)» — без солнца. Это превью: тени пропов, отражённый свет и туман игры не считаются.

## Общие темы, кражи, характер NPC, мастера, избранное

- **Общие темы** («Логика» → «+ тема»): вопрос игрока и ответ NPC у всех NPC проекта выбранных классов или фракций
  («Что тут происходит?» у любого горожанина), с условиями, действиями и «один раз у каждого». При сохранении темы
  вписываются в диалоги этих NPC (узлы 9000+, перед «Пока»; после ответа — снова список вопросов), NPC без своих
  реплик получает короткий диалог: приветствие тем (на странице темы), темы, «Пока». Файл `scripts/rpg/topics.txt` —
  для «Импорта мира», вписанное в диалоги при импорте пропускается. NPC, поставленные только в Hammer, тем не получают.
- **Владелец контейнера** (страница контейнера, «Замок и пополнение»): NPC или фракция. Под прицелом — красное
  «Украсть» и «Владелец: …»; если взятие видит владелец или член его фракции (в поле зрения, до 1200 ед.; вплотную —
  всегда), он говорит фразу события «кража» и нападает, репутация у фракции падает (правило `rep_theft`, вкладка РПГ).
  В Hammer — ключ `owner` у `prop_loot_container` / `func_loot_container`.
- **Агрессия и смелость** (NPC → «Персонаж» → «Бой»), как в New Vegas: не нападает первым / на врагов / на всех,
  кроме друзей / бешеный; трус убегает сразу, осторожный — при 50 % здоровья, обычный — при 25 %, храбрый не убегает.
- **Звуковые сцены локации ночью и в дождь** (страница зоны): игра меняет сцену сама, в том числе пока игрок внутри.
- **Мастера** (меню «Мастера»): новый торговец (товары, деньги, диалог торговли, место перед камерой окна карты),
  задание «принеси / убей / поговори» (цель и варианты «Есть работа?» / «Готово» у заказчика), патруль ГО (метрокоп,
  маршрут-квадрат вокруг камеры, пакет «патруль»). Получаются обычные данные проекта — дальше правятся на страницах.
- **Избранное** в окне объектов: ПКМ по пункту → «★ В избранное», раздел сверху; хранится в проекте.

## Терминалы и взлом замков

- **Вкладка «Логика» → «+ терминал»**: компьютер (зелёный ЭЛТ) или консоль Альянса. Название, приветствие, **записи**
  (текст для чтения — лор, дневники, приказы; его действия выполняются при первом прочтении), **команды** (без текста:
  действия + ответ экрана), **подменю** («+ в подменю»), у каждой — «Показывать, если» и «Один раз». **Замок**: сложность
  0–100 (0 — открыт), навык (Наука), предмет-пароль (записка открывает сразу). Справа внизу — превью экрана как в игре.
- **На карту**: палитра «Терминалы» или ПКМ по карте → «Поставить сюда» → «Терминал: компьютер / экран Альянса»; в свойствах
  объекта — какой терминал (`+` — новый, «Открыть» — к его записям) и модель. Экраны стандартных моделей игра знает; для своей
  модели — «Дополнительные ключи» `screen_pos`, `screen_ang`, `screen_size`.
- **Действия** «Дверь» (открыть и отпереть / закрыть / запереть / отпереть), «Силовое поле» (выключить / включить),
  «Турели и камеры» (отключить / включить / перепрограммировать — стреляют по Альянсу; без имени — все в 1500 ед. от терминала).
- **Взлом замков** в игре — мини-игра со шпильками: у контейнера и двери «Взлом (навык)» — сложность. Шпилька — стандартный
  предмет `bobby_pin` («…» в «Предметах»): кладите в списки лута и торговцам.

В игре: `rpm_terminal_debug 1`, `rpm_terminal_reset`, `rpm_lockpick_debug 1`, `rpm_lockpick_reset`.

## Диалоги (холст)

- колесо — масштаб к курсору; средняя/правая кнопка или Пробел+ЛКМ — двигать; **F** — вписать всё
- двойной клик по пустому месту / **N** — новая реплика; **Delete**, **Ctrl+D**, **Ctrl+L** (авто-раскладка)
- кружок справа у ответа → тянуть к реплике = связать; в пустое место = создать реплику
- WAV/MP3 перетащить на реплику — озвучка на языке из списка «Язык» сверху;
  несколько файлов на холст или «Озвучка из папки…» — привязка по именам `0.wav`, `105.wav`, `returning.wav`, `<номер>_<вариант>_after.wav`
- плашки языков в шапке реплики: зелёная — озвучка + липсинк, жёлтая — липсинк создастся при сохранении,
  серая — нет озвучки, красная — файла нет; красные буквы — нет перевода
- бейджи ответов: `+квест` выдаёт, `✓` завершает, `✗` проваливает, `этап`, `если` (условия), `✕` закрывает диалог

## Языки в игре

Один файл несёт все языки: `"line"` — основной язык проекта, `"line_russian"` — перевод; так же `text`,
`after_line`, `returning_line`, `display_name`, `title`/`desc` квестов, названия контейнеров (`loot_displayname_<язык>`)
и озвучка `choreo_<язык>` / `sound_<язык>`. Игра берёт язык из `dialog_language` (пусто = язык игры:
`cl_language` / Steam). Проверка: `dialog_language english` / `russian` в консоли.
