# HL2RPM Creation Kit

Редактор контента мода HL2RPM «по типу GECK»: карты в 3D с NPC, маркерами (кровати,
стулья, столы, стены), предметами, контейнерами и маршрутами; NPC с распорядком дня
(пакеты ИИ), фракции; диалоги, квесты и озвучка.
Запуск: `E:\SourceModding\HL2RPMSOURCE\HL2RPM Creation Kit\HL2RPM Creation Kit.exe`
(сборка — `build_editor.ps1`, исходники — эта папка, точка входа `hl2rpm_creation_kit.py`).

## Проект

Проект (`*.hl2dlg`, JSON) хранит всех NPC (реплики на всех языках, «персонажа» и
распорядок), квесты, фракции, всё, что поставлено на каждую карту, и узлы навигации.
**Ctrl+S** сохраняет проект и раскладывает файлы по папкам игры («Папка игры» в настройках):

| Что | Куда |
|---|---|
| диалог NPC + его квесты, все языки (только у NPC с репликами) | `scripts/dialogs/<targetname>.txt` |
| озвучка (WAV/MP3/OGG/FLAC → WAV 16 бит моно для Source) | `sound/dialogs/<targetname>/<язык>/<номер>.wav` |
| сцена с липсинком (генератор мода) | `scenes/dialogs/<targetname>/<язык>/<номер>.vcd` |
| персонаж: класс, модель, оружие, фракция, флаги, лут, распорядок | `scripts/npcs/<targetname>.txt` |
| что поставлено на карту | `scripts/world/<карта>.txt` |
| узлы навигации карты | `scripts/world/<карта>_nav.txt` |
| фракции и отношения | `scripts/world/factions.txt` |

Файлы, которые программа записала сама (заголовок `HL2RPM Creation Kit: generated`), она сама
и убирает; чужой файл перед первой перезаписью копируется в `*.bak_<дата>`.
Файл → «Импорт мира из игры» загружает `scripts/npcs` и `scripts/world` в проект.

## Карта (окно в 3D)

Сверху выбирается карта (`.bsp` из `hl2rpm\maps` и `testmaps\maps`; после компиляции в Hammer — ⟳).
Видно всё как в игре: мир, дисплейсменты, статические пропы, NPC из Hammer; плюс объекты проекта.

- **правая кнопка + WASD** — полёт (Q/E — вниз/вверх, Shift — быстрее, колесо при зажатой правой — скорость),
  колесо — вперёд/назад, средняя кнопка — сдвиг, **F** — к выделенному
- **левая кнопка** — выделить; тащить — двигать по поверхностям (Ctrl — по сетке 16), **Alt+тащить** — повернуть
  лицом к курсору, **[ ]** — поворот на 15°, **Delete** — удалить, **Ctrl+D** — копия
- слева «**Объекты**»: двойной клик → клик на карте — поставить NPC проекта, маркер, предмет, контейнер,
  проп, маршрут патруля (клики — точки, Enter или правая кнопка — готово), свою сущность; Shift+клик — несколько
- правая кнопка на карте — «Поставить сюда», «Опустить на пол», «Игра отсюда», «Вид сверху сюда»
- слева «**На карте**» — всё поставленное и NPC из Hammer; клик — выделить, двойной — показать
- ползунок **«Время»** — где кто в этот час: подпись над NPC и линии к месту текущего пакета
- **Навигация ▾** → «Сгенерировать в игре»: игра загружает карту, раскладывает узлы (`rpm_nav_generate`),
  программа забирает их в проект; «Править узлы» — клик добавляет, тащить — двигать, Delete — удалить
- **▶ Игра отсюда** (F6 с окна карты) — сохранить и запустить карту, игрок появится на месте камеры, время — с ползунка

## NPC: Диалог / Персонаж / Распорядок

- **Персонаж** — класс (горожанин, ГО, солдат, вортигонт, зомби…), модель (… — выбрать любую из игры), скин,
  оружие, здоровье, фракция, отношение к игроку, отряд; «враг, если ранить», «молчит, если ранить»,
  «бессмертный», «можно позвать в отряд игрока»; лут трупа; где стоит на картах; дополнительные ключи.
- **Распорядок** — пакеты ИИ. В каждый момент работает **первый** пакет списка, у которого подходит время
  и условие квеста (как в GECK). Суточная шкала сверху показывает, что NPC делает в каждый час.
  Пакеты: Сон, Еда, Свободное время, Патруль, Бродить, Идти и остаться, Охрана, Маркер, Стоять,
  Следовать, Заговорить (подходит к игроку и открывает свой диалог). Бой, скрипты карты и разговор с игроком
  прерывают распорядок. Распорядок есть у горожан, Аликс, Барни, вортигонтов, ГО, солдат, зомби.
- **Маркеры** (кровать, стул/диван, стол, стена, земля, работа, пост, точка ожидания) — место и анимация
  (из `actbusy.txt` игры); владелец — только этот NPC («своя кровать»). Ставьте маркер туда, где должен
  оказаться NPC, стрелка — куда он смотрит. Отметка «✓ у модели есть эта анимация» — проверка по модели NPC.
- **Фракции** — слева «Фракции»: отношение к игроку и к другим фракциям (= ftag NPC).

**F5** — пройти диалог прямо в программе, **F6** — запустить в игре, **F8** — обновить диалоги и мир в
запущенной игре (`-hijack +dialog_reload +rpm_world_reload 1`: объекты слоя создаются заново),
**F7** — проверка проекта (ссылки диалогов, пакеты без маршрута/маркера, повторы имён, переводы, озвучка).

В игре: `rpm_ai_debug 1` — над NPC пакет и что он делает, `rpm_world_dump` — список, `sv_timecycle_set_time 23` — время.

## Диалоги (холст)

- колесо — масштаб к курсору; средняя/правая кнопка или Пробел+ЛКМ — двигать; **F** — вписать всё
- двойной клик по пустому месту / **N** — новая реплика; **Delete**, **Ctrl+D**, **Ctrl+L** (авто-раскладка)
- кружок справа у ответа → тянуть к реплике = связать; в пустое место = создать реплику
- WAV/MP3 перетащить на реплику — озвучка на языке из списка «Язык» сверху;
  несколько файлов на холст или «Озвучка из папки…» — привязка по именам `0.wav`, `105.wav`, `returning.wav`, `<номер>_<вариант>_after.wav`
- плашки языков в шапке реплики: зелёная — озвучка + липсинк, жёлтая — липсинк создастся при сохранении,
  серая — нет озвучки, красная — файла нет; красные буквы — нет перевода
- бейджи ответов: `+квест` выдаёт, `✓` завершает, `✗` проваливает, `этап`, `если` (условия), `✕` закрывает диалог

## Языки в игре

Один файл несёт все языки: `"line"` — основной язык проекта, `"line_russian"` — перевод; так же `text`,
`after_line`, `returning_line`, `display_name`, `title`/`desc` квестов, названия контейнеров (`loot_displayname_<язык>`)
и озвучка `choreo_<язык>` / `sound_<язык>`. Игра берёт язык из `dialog_language` (пусто = язык игры:
`cl_language` / Steam). Проверка: `dialog_language english` / `russian` в консоли.

## Сборка

```
powershell -File build_editor.ps1
```
Создаёт venv (PySide6, PyOpenGL, numpy, PyInstaller) в `E:\SourceModding\HL2RPMSOURCE\dialog_editor_build`
и кладёт программу в `E:\SourceModding\HL2RPMSOURCE\HL2RPM Creation Kit`.
Без сборки: `python hl2rpm_creation_kit.py [проект.hl2dlg]`.
Снимок окна для отчёта: `--shot out.png --map ck_test --tab map --cam x,y,z,pitch,yaw --select ref:10 --hour 23 --npc ck_worker --npc-tab 2`.

Липсинк — копии генераторов мода (`dlgedit/lipsync_gen/vcd_english.py`, `vcd_russian.py`,
из `testmaps/scenes/demo_npc_1*/generate_vcd*.py`); новый язык — свой `vcd_<язык>.py`
и строка в `lipsync._GENERATORS` (без него — английские правила).
Чтение игры: `dlgedit/world/` (VPK, пути `gameinfo.txt`, BSP, VTF/VMT, MDL), окно карты — `dlgedit/ui/worldview.py`.
