# hl2rpm_extras/art — icon, logo, UI fonts, Steam assets

Everything here is original artwork generated by the scripts in `src/` (PIL + numpy, no external images),
except the fonts (SIL OFL 1.1, unmodified, from github.com/google/fonts).

| What | File | Notes |
|---|---|---|
| Mod icon for Steam / gameinfo `icon "resource/icon1"` | `MOD/resource/icon1.tga` (16), `icon1_big.tga` (32), `icon1_thumb.tga` (32) | 32-bit uncompressed TGA, type 2, bottom-left, 8 alpha bits, no footer — same layout as `mapbase_episodic/resource/icon1*.tga` |
| Icon masters | `icon_256.png`, `icon_184.png` (Steam community icon), `icon.ico` (16/32/48/256), `icon/icon_<N>.png` (16…1024) | |
| Steam library logo | `steam/library_logo_1280x720_{en,ru}.png` | transparent |
| Main menu logo | `menu_logo_1024x256_{en,ru}.png` | transparent, left-aligned; needs gameinfo `gamelogo 1` + `resource/GameLogo.res` + a VGUI material to show in game |
| Lockup masters | `steam/logo_lockup_{en,ru}_full.png` (3113×683) | for any other Steam capsule / store art |
| UI fonts | `fonts/` (copy of `MOD/resource/fonts/`) | face names and roles — `fonts/README.txt` |
| Previews | `previews/` | concept sheets, size comparisons, logo over game screenshots, font sheets |

Design: icon = an ID bracelet (the mod's «браслет» interface): strap, steel-blue bezel, dark display with a
lambda in Combine blue (110 190 255) and an amber status LED (255 170 60); wear (scratches, chips, mottling)
from 64 px up; 16 px is hand-placed pixel art (`LAMBDA16` in `make_icon.py`). Logo = emblem + "HALF-LIFE 2"
+ "RP" registry tag, Combine rule with amber start, subtitle justified to the text width
(Fira Sans Condensed Bold / SemiBold).

Regenerate (from this folder; MOD = `E:\Steam\steamapps\sourcemods\hl2rpm`):

```
python -I src/make_icon.py concepts previews            # 3 concepts + comparison sheet
python -I src/make_icon.py refine previews              # concept A vs final
python -I src/make_icon.py final . MOD/resource         # icon PNG/ICO + the three TGAs
python -I src/make_logo.py MOD/resource/fonts . <backdrop.jpg ...>
python -I src/overview.py . previews/art_overview.png
python -I src/fontinfo.py MOD/resource/fonts/*.ttf      # GDI names, OS/2, Cyrillic coverage
python -I src/gdi_fontcheck.py MOD/resource/fonts previews/fonts_gdi_render.png
python -I src/fonts_preview.py check MOD/resource/fonts/*.ttf
```
