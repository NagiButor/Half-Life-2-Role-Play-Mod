// Один блок = один голос ("voice" в диалогах), имя блока = id голоса = папка звука
// sound/vo/hl2rpm/<english|russian>/<voice>/<ID>.wav.
//
// Ключи карточки:
//   name / name_en      имя персонажа
//   npc                 targetname(ы) NPC через запятую, можно маску npc_cp_* (так build_content.py
//                       находит голос диалога, если в нём не указан "voice")

//   processing          обработка после записи: none / mask_light / radio_cp / pa_overwatch /
//                       radio_overwatch / vort / close_dry (рецепты — Дизайн-документ/Озвучка/README.md)
//   vo                  new (новая запись) / mixed (ваниль, где подходит, + новая) /
//                       vanilla (только ванильные файлы) / text (пока только текст) / none (молчит)
//   priority            порядок записи (Part VI/02 §6.2): 1 Надзор и ГО, 2 главный квест, 3 спутники,
//                       4 квестодатели фракций, 5 побочные, 6 массовка
//   model               модель HL2 (стоковая замена, пока нет своей)
//   prompt_en           описание голоса для Voice Design (ElevenLabs и т.п.) — только характер голоса,
//                       без имён реальных актёров и без «как в игре X»
//   tts_voice           имя/ID выбранного синтетического голоса (заполняет тот, кто озвучивает)
//   notes               прочее
//   references          3 эталонные реплики для пробы голоса (ru/en), из Part V; [проба] — придуманы для пробы
