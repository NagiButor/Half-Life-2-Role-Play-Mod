# hl2rpm_extras

Файлы проекта, которые живут вне `sp/src`, но должны храниться в git.
Здесь лежат **копии**; рабочие файлы остаются на своих местах — после правки
там скопировать сюда и закоммитить.

| Папка | Рабочее расположение |
|---|---|
| `fgd/` | `E:\XBLAH's modding tool\tools\FGDs\Mapbase` (Hammer++ грузит их оттуда) |
| `crashtools/` | `E:\Steam\steamapps\sourcemods\hl2rpm\crashtools` |
| `resource/` | `E:\Steam\steamapps\sourcemods\hl2rpm\resource` — локализация мода (`hl2rpm_<язык>.txt`, UTF-16LE **с BOM**), `gamemenu.res`, `clientscheme.res` (шрифты `RPMUI_*` окон M6 — `game/client/hl2rpm_ui.*`) |
| `scripts/` | `E:\Steam\steamapps\sourcemods\hl2rpm\scripts` — `hl2rpm_pbr.txt` (из чего сделаны материалы, PBR), `hl2rpm_relief.txt` (исключения рельефа материалов без карты нормалей), `HudLayout.res` |
| `materials/` | `E:\Steam\steamapps\sourcemods\hl2rpm\materials` — текстовые материалы мода: `hl2rpm/water/*.vmt` (типы воды: чистая, мутная, болотная, морская, радиоактивная — `$water_absorb`/`$water_glow`, `stdshaders/water.cpp`) |
| `tools/` | скрипты-генераторы и dev-утилиты (оригиналы, рабочих копий нет) — см. ниже |
| `imported/` | отчёты `import_gma.py`: что из каждого аддона Garry's Mod легло в мод, что пропущено и почему |
| `art/` | исходные картинки пользователя: `lambda_graffiti_src.jpg` (лямбда-графити меню и Steam; «прозрачность» нарисована шахматкой — её вырезает `make_menu_assets.py`), `icon_src.jpg` (значок мода), `loading_valve_ref.png` (референс вентиля экрана загрузки) |
| `../AI_instructions/skills/` | канонические процедуры для любой AI-модели: `hl2rpm-hammer`, `hl2rpm-playtest`, `hl2rpm-dialogs`, `hl2rpm-voice`. Старый каталог `claude_skills/` содержит указатель на общую базу; клиентские `.claude/skills` и `.agents/skills` — локальные junction на неё |

### tools/

| Скрипт | Что делает |
|---|---|
| `generate_weather_sounds.py <папка>` | синтезирует петли дождя/ветра для `sound\hl2rpm\weather\` |
| `make_thunder.py` | режет записи грома из `E:\SourceModding\ProceduralWeatherAndSkyPromt\lighting sounds` (нужен ffmpeg) в `sound\hl2rpm\weather\thunder\close_*/mid_*/far_*.wav` |
| `make_lightning_tex.py` | генерирует `materials\hl2rpm\weather\lightning_glow.vtf` + `lightning_bolt.vmt` (канал молнии) |
| `make_vitals_assets.py [--seed N] [--preview]` | ассеты «раненого» взгляда без костюма (`hl2rpm_vitals.cpp`, `hl2rpm_lowhealth_ps30`): `materials\hl2rpm\effects\lowhealth_veins.vtf` (вены от краёв экрана: r — сосуды, g — порядок появления, b — пятна края красноты, a — ореол) и `sound\hl2rpm\player\heartbeat_once.wav` (один удар из зацикленного стокового `player/heartbeat1.wav`) |
| `add_loc_tokens.py` | вписывает токены `#HL2RPM_*` в `resource\hl2rpm_<язык>.txt` мода (UTF-16LE с BOM, делает `.bak_`) — после запуска скопировать файлы в `resource/` здесь |
| `fgdcheck.py <fgd>...` | упрощённая проверка FGD в порядке загрузки Hammer (скобки, неизвестные base-классы) |
| `install_compilers.ps1 [-NoBuild]` | собирает компиляторы карт мода (форк vbsp/vvis/vrad Mapbase в `utils/`) и ставит их в `bin` SDK как `hl2rpm_vbsp/vvis/vrad.exe` (+ `hl2rpm_*_dll.dll`); их запускают Hammer++ и `compile_map.ps1` |
| `run_tour.ps1 -Map <карта> -Extra "<+команды>"` | запускает фото-тур погоды, выводит скриншоты и важные строки `console.log` |
| `dmx_dump.py <file.pcf> [фильтр]` | дамп систем частиц из бинарного `.pcf` (операторы и их параметры) |
| `dmx.py` | чтение/запись бинарного DMX (`.pcf`) — модуль для скриптов ниже |
| `make_weather_pcf.py` | собирает `particles\hl2rpm_weather.pcf` мода (дождь, ливень, снег, пепел с операторами `HL2RPM Precip *`) из `rain_fx.pcf` (mapbase_shared VPK); параметры систем — в начале скрипта |
| `flicker_stats.py <папка jpg> <out.png>` | покадровая разница серии скриншотов/кадров `startmovie` — поиск мерцания |
| `crawl_stats.py <папка> <префикс> <out.png>` | вторая разность по времени (≈0 при плавном движении) — «ёрзанье» теней при ходе солнца, «песок» на облаках; кадры писать в `tga` |
| `vpk_list.py <dir.vpk> [фильтр] [--extract папка]` | список/распаковка файлов из VPK |
| `make_gi_test.py <out.vmf>` | генерирует тестовую карту `gi_test` для непрямого света: комнаты с окнами / глухая / с люком в крыше / с воротами (использует `vmf.py` и `new_test_map.py` из навыка `hl2rpm-hammer`; компилировать `compile_map.ps1`) |
| `pom/` | исследование рельефа (POM) из текстур без карт нормалей: `vtf.py` (чтение VTF, DXT1/3/5 → numpy), `relief_proto.py` (знак рельефа по яркости против высоты из настоящих карт нормалей на 174 стоковых материалах), `relief_proto4.py`/`relief_proto7.py` (детектор светлой сетки швов по связности), `relief_sheet.py` (листы «текстура + высота» материалов без нормалей), `relief_dump.py <материал> [inv]` (высота, освещённый рельеф и нормали одной текстуры). Путь к распакованным VPK — `R` в `relief_proto.py` |
| `make_water_test.py <out.vmf>` | генерирует тестовую карту `water_test`: ряд бассейнов из стоковых материалов воды (мутная, прозрачная, морская, канализация, дешёвая...) со ступенями глубины 16/64/128/256 ед.; солнце карты совпадает с солнцем deferred в 13:00 - для сравнения с `-nodeferred`; бассейны 10-14 — типы воды мода (`materials/hl2rpm/water`), 15 — стоковая токсичная слизь |
| `item_models/make_suit_piles.py [suit_hev suit_pcv suit_cp suit_soldier suit_prison suit_elite suit_worker suit_hazmat] [--preview <папка>]` | костюмы-предметы «как в New Vegas / Сталкере»: сложенная одежда (мягкие плиты со складками и слоями, грани на куске текстуры самого персонажа — квадрат внутри треугольников его торса / ног), рядом твёрдые части из модели персонажа — шлем или маска (кости головы), броня торса, сплющенная «пустым жилетом» (позвоночник, ключицы), баллон химзащиты (группа тела `Backpack`); двусторонние, `$staticprop`, материалы персонажа. `--preview` — рендер в Blender (`blender_preview.py`) |
| `item_models/make_item_models.py [модели] [--no-bake] [--no-compile] [--render]` | модели мелких предметов, сделанные кодом в Blender 5.1 (`item_models/blender_items.py`): шпилька, два ключа; запекание, VTF/VMT, QC, `studiomdl`; исходники — `modelsrc\hl2rpm_items` рядом с `mapsrc` |
| `hd_textures.py <карта.bsp, материал или список.txt>` / `--textures <список> [--inplace]` | HD-версии текстур (Real-ESRGAN + перенос деталей, свой DXT/VTF): мира — в `materials/hd` (`$hdtexture`), лиц и оружия — поверх стоковых путей в моде (`materials/hd_inplace.txt`), декалей — в `materials/hd/decals` |
| `make_menu_assets.py` | ресурсы главного меню и паузы (`game/client/hl2rpm_mainmenu.cpp`): `materials/vgui/hl2rpm/menu/` — фон-стена, лямбда-графити пользователя (`art/lambda_graffiti_src.jpg`, вырезана из нарисованной шахматки: фон каждой клетки 40 px по её тёмным пикселям, альфа — яркость над фоном, плоские «полы» альфы у клеток другого оттенка убираются), заголовок «HALF-LIFE² / ROLE PLAY MOD», зерно, виньетка, пылинка, значок |
| `make_loading_valve.py` | вентиль экрана загрузки: литой маховик (шестигранник с шарами на углах, гайка ромбом — по референсу пользователя) в Blender (`item_models/blender_valve.py`), 32 кадра шестой части оборота → `materials/vgui/hl2rpm/menu/loading_valve` (8×4 по 128 px) |
| `make_menu_music.py` | синтез трека меню (ре минор, 80 BPM, ~166 с; гул, металл, радиопомехи, пэды, FM-пиано, свёрточная реверберация) → `sound/music/hl2rpm/menu/hl2rpm_menu_theme.mp3` (нужен ffmpeg) |
| `make_steam_assets.py [--grid]` | значок мода — картинка пользователя `art/icon_src.jpg`, вырезанная из тёмного фона (ico 16–256: и `resource/game.ico` — значок окна игры, и `resource/icon1(_big).tga` для `gameinfo.txt`, значки сообщества/клиента) и картинки Steam с лямбдой-графити: фон библиотеки 3840×1240, логотип 1280×720, обложки 600×900 и 920×430, размеры магазина → `E:\SourceModding\HL2RPMSOURCE\steam_assets`; `--grid` копирует в `Steam\userdata\<id>\config\grid` под три предполагаемых ID ярлыка |
| `import_gma.py <файл.gma> [--only <префикс>] [--force]` | распаковка аддона Garry's Mod в мод: без lua/значков, файлы игры не перезаписывает (без `--force`), VTF 7.5 → 7.4, модели MDL v49 пропускает (их пересобирают скрипты ниже); отчёт — `imported/<аддон>.txt` |
| `mdl_decompile.py` | свой разбор MDL/VVD/VTX/PHY → SMD + QC (кости, сетки, скины, группы тел, аттачменты, хитбоксы, анимации с событиями, IK-цепи, физика) и `compile_qc()`; QC пишет `$origin 0 0 0 -90` (studiomdl поворачивает модель на 90°) — модуль для скриптов ниже |
| `make_characters.py [имена]` | персонажи и пропы из аддонов, пересобранные под SDK 2013 (`models/hl2rpm/characters/`): `hev_mk5` (HEV Mk V с твёрдым визором, скин 1 — P.C.V.), `synth_elite(_green)`, `super_soldier_beta`, `cremator`; пропы `combine_immolator`, `combine_spear`; исходники — `modelsrc\hl2rpm_characters` |
| `make_hands.py [citizen hev cp soldier prison elite worker hazmat]` | руки от первого лица, вырезанные из тела костюма (`models/hl2rpm/hands/`, `$bonemerge` костей ValveBiped) — для `hand_viewmodel` Mapbase у оружия с `"uses_hands" "1"` |
| `make_vm_hands.py [костюмы] [--preview out.png]` | руки стокового оружия HL2 под костюм: части `v_hand_sheet` (перчатка, манжета, рукав, оранжевая пластина HEV — по UV-треугольникам всех стоковых вьюмоделей) перекрашиваются в цвета рук костюма (средняя половина пикселей его кисти / предплечья + мелкое зерно) поверх складок и швов оригинала; карта нормалей — оригинал, сглаженный для кожи и резины → `materials/models/weapons/v_hand/hl2rpm/v_hand_sheet_<костюм>(_normal)` (клиент меняет текстуры материала: `hl2rpm_vmhands.cpp`) |
| `make_zombie_hazmat.py` | зомби в химзащите, как зомби аддонов: от костюма рабочего из аддона только одежда (без шлема, капюшона, перчаток), голова, когти и дальняя треть предплечий — классического зомби, его скелет, хитбоксы, рэгдолл и хедкраб (часть тела 1, как ждёт `npc_zombie`), анимации — `$includemodel "zombie/classic.mdl"` (пересобранные из кадров теряют движение — NPC стоял) → `models/hl2rpm/characters/zombie_hazmat.mdl`, один скин — в крови |

| `make_melee_weapons.py [имена] [--no-upscale] [--no-subdiv]` | оружие ближнего боя из HL2 Melee Pack: вьюмодели и мировые модели (`models/weapons/hl2rpm/v_/w_<имя>`), сглаживание сеток в Blender (`item_models/blender_subdiv.py`, жёсткие рёбра сохраняются), апскейл текстур (`materials/models/weapons/hl2rpm_melee/`), скрипты `scripts/weapon_rpm_<имя>.txt`; у трубы мировая модель — стоковая труба Мэтта (`props_canal/mattpipe`) |
| `make_beretta.py [--no-upscale] [--report] [--preview <папка>]` | Беретта 92 (аддон «Dual Berettas» переосмыслен как один пистолет): пистолет из `v_pist_elite` CS:S, анимации одиночного пистолета `v_pist_p228` (зеркало: CS:S собирает под левую руку), перенос на кости рук ValveBiped под руки костюма (`uses_hands`), масштаб ×1.34 от глаза, FOV 74; `models/weapons/hl2rpm/{v,w}_beretta.mdl`, текстура (апскейл), звуки CS:S, `scripts/weapon_rpm_beretta.txt`, звуковые скрипты; `--preview` — вид от глаза без игры.
