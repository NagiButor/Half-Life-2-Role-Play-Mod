## 1) Красивое уведомление о награде (Fallout-style)
- Сейчас уведомление формируется на сервере в `InventorySystem::NotifyPlayerPickup()` как plain-строка `You picked up: ...` и отправляется через `ui_toast`.
- Сделаю формат и рендер “как в Fallout”:
  - сервер будет слать структурированное сообщение в `ui_toast`, например `REWARD|<friendlyName>|<count>` (count по умолчанию 1).
  - клиентский `CToastNotificationPanel` будет:
    - держать очередь сообщений (несколько подряд наград не будут затирать друг друга),
    - рисовать слева сверху, не по центру,
    - для `REWARD|...` рисовать 2 сегмента разным цветом: `Вы получили` (серый) + ` <предмет> xN` (золото), с тем же аккуратным фоном/скруглением.
- Для квестов будет передаваться корректный `count` (чтобы было `x3`, а не 3 отдельных тостов).

## 2) Лут-панель: убрать стартовую подсветку верхнего предмета
- Причина: в `CVGuiLootPanel::BeginLoot()` в конце принудительно ставится `m_nSelectedLeftIndex = 0` / `m_nSelectedRightIndex = 0`, из-за этого первый элемент всегда “armed/selected”.
- Исправление:
  - на старте оставлять `m_nSelectedLeftIndex = -1` и `m_nSelectedRightIndex = -1`,
  - оставить только `m_nFocusedColumn` (чтобы навигация клавишами работала),
  - подсветка появится при первом движении по клавишам/клике, а не сразу.

## 3) Проверка
- Проверю, что:
  - при выдаче нескольких наград тосты красиво стекуются и не моргают,
  - текст выглядит как “Вы получили …”,
  - при открытии лута ничего не подсвечено, но стрелки/клик сразу выбирают предмет.
- Прогоню диагностику IDE после правок.

Файлы правок: `inventory_system.cpp` (сервер), `vgui_inventorypanel.cpp` (toast/UI), `vgui_lootpanel.cpp` (loot selection).
