## 1) Верхняя плашка Inventory/Quests (без «кнопок» и без красного)
- Убрать текущий tab-класс, который рисует красную заливку/рамку (из-за этого одна вкладка постоянно красная).
- Сделать вкладки визуально как обычные надписи (золотой текст), а активную вкладку отмечать только тонким золотым подчёркиванием.
- Сделать ровно **одну** аккуратную вертикальную линию 1px между надписями (без горизонтальной линии под ними).

## 2) Исправить пересечение верхней плашки с кнопками списка
- Удалить текущую горизонтальную линию в фоне панели (она и создаёт ощущение пересечения).
- Подогнать отступы: увеличить `viewTop` на несколько пикселей, чтобы первая кнопка списка гарантированно начиналась ниже header-зоны.

## 3) Убрать белый текст в описании квеста
- Принудительно назначать золотой цвет `QuestDesc` не только при создании, но и в `ApplySchemeSettings()`/при открытии панели (чтобы схема VGUI не возвращала дефолтный белый).

## 4) Менять название/описание при изменении стадии
- Расширить определение квеста: добавить блок стадий в `scripts/dialogs/*.txt`:
  - `stages { "0" { title/desc/kill_targets/kill_count } "1" { title/desc } ... }`
- На сервере при отправке `Quests_Update` подставлять title/desc **текущей стадии**, а не общие поля квеста.
  - Пример: стадия 0 “Kill headcrab”, стадия 1 “Return back”.

## 5) Прятать completed/done квесты (toggle)
- На вкладке Quests добавить строку-переключатель “Completed (N)” (золотая, без кнопочного оформления).
- По умолчанию скрывать completed, по клику разворачивать/сворачивать список completed.
- При сворачивании сохранять выбранный квест (если он был completed — переносить выбор на ближайший активный).

## 6) Многостадийные квесты (комплексные)
- В `QuestDef` добавить массив `stages` (каждая стадия — свой objective).
- Логика progression:
  - у активного квеста учитывается текущая стадия;
  - если у стадии есть kill-условие и оно выполнено — увеличить stage, сбросить progress, отправить toast + обновить `Quests_Update` (чтобы на клиенте поменялось название/описание).
- Для стадий без objective (например “Return back”) прогресс не тикает автоматически — стадия меняется только через диалог (сдача/переход).

## 7) Награды за квесты (вещи в инвентарь)
- В `quests` добавить блок `rewards`:
  - `rewards { "item_healthkit" "1" "ammo_pistol" "30" }`
- На `CompleteQuest()` выдавать награды через InventorySystem:
  - обычные предметы: `AddItemToPlayer` N раз;
  - ammo-итемы: `AddItemToPlayerWithBullets` (суммарные bullets).
- После выдачи — отправлять `Inventory_Update` и toast “Reward received”.
