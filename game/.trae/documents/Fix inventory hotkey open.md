## Почему кнопка/бинд инвентаря перестал работать
- Я убрал авто-открытие в `CVGuiInventoryPanel::SetItems()` (теперь оно открывает UI только если панель уже видима).
- Но `inventory_request_local` при нажатии `I` **не открывает панель**, он только шлёт `inventory_request` на сервер.
- В итоге сервер присылает `Inventory_Update`, `SetItems()` обновляет данные, но окно не появляется — выглядит как «кнопка не работает».

## Исправление (без возврата авто-открытия на наградах)
- Оставить поведение `SetItems()` как есть (чтобы награды не открывали UI).
- В `__Cmd_Inventory_Request_Local` (ветка, когда панель не видима):
  - принудительно открывать панель **именно в табе Inventory** (даже если последний раз был Quests),
  - затем отправлять `inventory_request`.

## Проверка
- Нажатие `I` открывает инвентарь сразу, затем список обновляется когда придёт `Inventory_Update`.
- Сдача квеста больше не открывает инвентарь сама по себе.
