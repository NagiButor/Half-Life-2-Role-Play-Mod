## Разбор причин
### 1) `cl_clear_nodecal 1` срабатывает только после рестарта уровня
- Сейчас снятие флага завязано на «окно времени после загрузки карты». Если включить `cl_clear_nodecal` позже — логика может уже не применять изменения.
- Решение: при смене ConVar на `1` запускать применение сразу и «перезапускать таймер» повторных применений.

### 2) Лом по живому NPC: нет кровавых декалей, по мёртвому есть; огнестрел работает всегда
- У живых NPC кровь/TraceBleed делаются только если `subInfo.GetDamage() >= 1.0` (порог) и кровь разрешена фильтром.
  - См. условие в [ai_basenpc.cpp](file:///e:/SourceModding/HL2RPMSOURCE/source-sdk-2013-mapbase-v8.0/sp/src/game/server/ai_basenpc.cpp#L1615-L1643)
- У трупов (ragdoll prop) другой путь — там кровь может появляться даже при мелком уроне, поэтому визуально «по мёртвому есть».
- Решение: сделать порог для `DMG_CLUB` (лом) меньше 1.0 или отключаемым ConVar’ом.

### 3) `npc_alyx` не даёт сплешей крови
- В `CNPC_Alyx::Spawn()` прямо выставлено `m_bloodColor = DONT_BLEED;`.
  - См. [npc_alyx_episodic.cpp](file:///e:/SourceModding/HL2RPMSOURCE/source-sdk-2013-mapbase-v8.0/sp/src/game/server/hl2/npc_alyx_episodic.cpp#L336-L363)
- Поэтому `SpawnBlood/TraceBleed` не дают эффекта крови.

## План правок в исходниках
### A) Nodecal без рестарта карты (client.dll)
1. Добавить callback на `cl_clear_nodecal` и `cl_clear_nodecal_filter`:
   - при включении/смене фильтра сразу вызывать `cl_clear_nodecal_apply`-логику.
   - сбрасывать внутренние таймеры системы, чтобы повторные применения начинались «сейчас», а не только при загрузке карты.
2. Разрешить `cl_clear_nodecal_duration 0` как режим «применять бесконечно» (пока cvar включен).

### B) Кровавые декали от лома по живым NPC (server.dll)
1. В `CAI_BaseNPC::TraceAttack` изменить условие крови:
   - либо сделать ConVar `ai_bleed_min_damage` (по умолчанию 1.0) и использовать её вместо жёсткого `>= 1.0`.
   - либо сделать исключение: если `info.GetDamageType() & DMG_CLUB`, то использовать меньший порог (например 0.01).
2. Перенести логику `ai_allow_face_decals_while_alive` (подмена surfaceprop на flesh для `HITGROUP_HEAD`) так, чтобы она работала независимо от порога крови (иначе для маленького урона по голове она не срабатывает).

### C) Кровь у Alyx (server.dll)
1. Добавить ConVar `ai_alyx_bleeds` (по умолчанию 1).
2. В `CNPC_Alyx::Spawn()` ставить `m_bloodColor = BLOOD_COLOR_RED`, если ConVar включён; иначе оставлять `DONT_BLEED` (ванильное поведение).

## Проверка после сборки
- `cl_clear_nodecal 1` должен начинать работать сразу в середине карты (без рестарта).
- Лом по живым NPC должен оставлять кровавые декали (на стенах/полу) при любом разумном уроне.
- `npc_alyx` должен давать сплеши крови при попаданиях.

Если подтверждаешь — внесу правки и пересоберу client/server DLL.
