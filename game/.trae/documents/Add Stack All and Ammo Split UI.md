## 1) Кнопка «Sort» (вместо “Stack”)
- В табе Inventory добавлю кнопку **Sort**.
- По нажатию клиент вызовет серверную команду `inventory_sort`.

## 2) Что делает Sort на сервере
- `inventory_sort` выполнит два действия:
  1) **Авто-стак**: объединит все записи, которые можно стакать (все `isWeapon==false` с одинаковым classname). Это покрывает патроны и любые “стекаемые” расходники.
  2) **Сортировка**: упорядочит инвентарь предсказуемо и красиво:
     - Сначала weapons, потом ammo, потом остальные items.
     - Внутри группы — по `classname` (алфавитно).
- После сортировки вызовет `SyncPlayerAmmoWithInventory` и `SendInventoryToPlayer`.

## 3) Разстакать патроны (Split на нужное количество)
- Для ammo-предметов добавлю действие **Split** (в UI рядом с Drop).
- Split открывает компактное окно внутри инвентаря (чёрный фон + золото, без нарушения эстетики):
  - название предмета,
  - поле ввода количества,
  - Confirm/Cancel.
- Confirm вызывает серверную команду `inventory_split <slotIndex> <amount>`:
  - проверка слота, что это ammo, диапазон `1..bullets-1`,
  - уменьшить bullets в исходной записи,
  - вставить новую запись сразу после исходной (`InsertAfter`) с указанным количеством,
  - `SyncPlayerAmmoWithInventory` + `SendInventoryToPlayer`.

## 4) Где будут правки
- Сервер: [inventory_system.cpp] — добавить `inventory_sort` и `inventory_split`.
- Клиент: [vgui_inventorypanel.cpp/.h] — кнопка Sort, добавление Split-экшена и маленького модального окна ввода.

- Проверю:

  - сортировка группируется (weapons/ammo/items).
  - Split 10 из 60 → остаётся 50 и появляется строка на 10 прямо под ней.
